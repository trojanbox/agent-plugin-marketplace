# Linked Anthology Series：语义路由回归设计

评估范围：`writing/fiction-linked-anthology-design` 和小说 Discussion、Outline、Manuscript Readiness、Drafting、Continuity、Final Review 以及 Divergent Ideation、GitHub Issue Manager 的最近邻边界。

本文件只记录预期路由与判据；运行时评估结果需基于届时实际规则另行核查。对应 ANTH001–ANTH020 已写入 `semantic-routing-regression.csv`。

## Gate

- **系列结构设计是主目标**：独立短/中篇共享世界、总体单元目录、跨篇线索、总主线证据与 reveal 安排 → 系列架构主导。
- **单篇人物、结局、题材开放决策** → Discussion；如需检查跨篇已有事实，可组合系列方法。
- **近期章节计划** → Outline；涉及跨篇信息才组合系列方法。
- **正式正文** → Drafting → Readiness；涉及已有确认的跨篇事实才条件加载系列方法；交稿时仍按既有规则执行 Prose Editing。
- **实际文本跨篇矛盾** → Continuity；系列方法只提供索引和信息边界。
- **原创离奇种子无系列交付要求** → Divergent Ideation。
- **一个真实独立的第二主交付物** → 保留两个主流程的冲突，不借 composition 吞并。

## 防退化点

1. 不用每篇都有主线彩蛋代替单篇故事；
2. 不预设所有异常同源，或必须有全知收容机构；
3. 不把 Series Ledger 缺失本身判为正文 Not Ready；
4. 区分世界真相、人物知情、档案编者知情与读者得到的信息；
5. 已否决候选与未确认的历史解释不可写回 Canon。

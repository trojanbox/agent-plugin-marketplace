# 恐怖方向库开发期样本：同题四方向

记录日期：2026-09-16。证据范围：本轮创作代理实际生成了以下四个片段，随后逐段做了人工式结构比较，并接受红队代理质疑；这是代理语义审阅，没有邀请人类读者、没有盲测、没有随机对照，也不是选择器自动生成的正文。

相关版本的方向库共有 14 维、252 条可组合部件、5 个研究或教学来源。条目数只说明数据规模，不能证明文学质量、恐怖效果或长期去同质化效果。

以下是本次实现的原创试写材料，用来人工审查库能否支持不同因果链，不是默认选项、整篇范文、剧情模板或用户作品。固定场景：两位成年家人在家中轮流照护行动不便的亲人。敏感类别：`medical`。四段都不靠查明异常起源、不靠多出物件收尾，但保留各自的具体异常后果。阅读时比较人物选择、推进与结尾功能，不以换名换道具计多样性。

### A. 维持照护：选择留在关系里，边界逐渐改变

样本性质：本轮实际试写 + 代理人工式结构比较；非人类读者盲测。

因果桥：妹妹要完成父亲每天的转身照护 → 她选择让父亲自行说出每次需要而不替他决定 → 家中一些原本自动完成的帮助停止，双方重新承担照护劳动 → 结尾落在一次需要等待的同意，关系仍在而默契已经改变。

> 她照旧伸手去扶父亲的肩。床垫先陷下去，父亲的身子已经侧过半寸，她的掌心还悬在睡衣上方。父亲看着她，没说疼，也没说不疼。
>
> 她把手收回来，问他现在要不要翻身。床垫慢慢平了。墙边那张床过去从来不会发出声音，此刻却响了一下，像有人把压着的膝盖移开。
>
> 父亲等了一会儿才说，要。她重新扶住他。这一次分量全在她手里，比昨天重，也比刚才实在。他翻好以后，她没有替他把下一句话说出来。

结构审阅：变化由“停止代替同意”造成，下一场要处理照护如何继续；没有寻找怪物弱点。仍需避免把行动不便者写成异常来源，父亲应有照护之外的生活与判断。

### B. 资源分配：公开劳动，把原来隐藏的承担显出来

样本性质：本轮实际试写 + 代理人工式结构比较；非人类读者盲测。

因果桥：哥哥要把照护排班交给下周的人 → 他发现各人都完成了自己的时间但实际照护仍有空档 → 他选择公开那些被默认无需认领的劳动 → 家人必须真实改变工作与休息安排 → 结尾完成一份有人认领的分工，安全仍有代价。

> 哥哥把周三下午空出来，说那两个小时谁都没在家。妹妹用指甲划过自己的名字，说她回来时父亲已经换好了衣服。父亲说，他一直等着，没人帮忙。
>
> 三人都看向床沿。那件换下的衣服叠得很好，湿气还没散，袖口里有两道压了很久的指印。哥哥把自己的名字写进空格，划掉了同一时间的外出安排。
>
> 笔离开纸面时，床沿向上弹了一下。父亲抓紧扶手，像一个刚被放下来的人。妹妹没有再说排班早就填满了。她把下午第一段时间往自己这边挪了半小时。

结构审阅：推进来自劳动分配及后果，结尾作用是让承担变得可见；没有靠新规则击败异常。下一版需把排班空档与工作压力写得可信，不能宣称公开填表就永久解决所有危险。

### C. 拒绝继承：不把未知责任交给不知情者

样本性质：本轮实际试写 + 代理人工式结构比较；非人类读者盲测。

因果桥：家人已经找到新的照护者，终于可以休息 → 妹妹看到原有帮助会在交接动作中转给新人 → 她选择中止未充分告知的交接并允许新人离开 → 自己承担短期后果，同时争取知情协作 → 结尾真正让一个人离开，余波是已经无法轻易卸下的责任。

> 新来的照护者伸手去接交接本时，门里的地砖响了两声。妹妹听得出来，那是父亲站起以前拖动脚跟的声音。父亲已经很久不能独自站起，今天却在床边坐得笔直，眼睛看着门口。
>
> 妹妹没有递本子。她先把约好的车费转过去，又把门往外推开一点，说有几件事还没讲清楚，今天先不用留下。床边的声音停了，父亲缓缓弯下腰，像有什么重量重新落回肩上。
>
> 那人走到楼梯口才问她要不要帮忙叫别人。她说要，但得先知道会接到什么。她看着对方走下去，没有再请人回头签字。

结构审阅：关键行为是知情交接与允许退出，结尾承认离开确实成功，不用异物追到新家撤销它。后续应展示共同承担的可能，避免把负责等同孤独受难或无限自我牺牲。

### D. 继续获益：人物选择不问，便利形成更深依赖

样本性质：本轮实际试写 + 代理人工式结构比较；非人类读者盲测。

因果桥：妹妹刚重新获得有收入的工作，不愿再错过排班 → 她发现一次含混求助能让自己的照护工作顺利完成，却使远处姐姐持续疲惫 → 她选择只报告父亲已经安顿好并再次使用帮助 → 原本偶发的获益进入固定安排 → 结尾落在一句真实但不完整的日常报平安，人物没有被安排立刻受罚。

> 姐姐在电话里说，昨晚又像陪人坐了一夜，腰直不起来。妹妹还没开口，父亲就在她手下轻了起来。她只用一只手便把他扶正；电话那头，姐姐吸了口气，把话停在半截。
>
> 妹妹先问姐姐是不是椅子不好。她本来准备说昨晚的事，门外却响起接她上班的喇叭。那份工作才做了三天，前两次她都迟到了。父亲坐得很稳，脸上终于没有费力的样子。
>
> 她向门外应了一声，告诉姐姐今天安排得过来。姐姐说那就好，明天还这个时候打来。妹妹没有纠正。她把父亲需要的东西放到手边，临走前又说了一遍，今天都安排好了。

结构审阅：推进来自真实获益与选择性隐瞒；人物有自利，也有照护与生计压力，不是单一贪婪标签。结尾通过重复的不完整实话延续默许，不用超自然报应裁决人物。仍需给姐姐独立生活和行动空间，不能让她永远只是转移代价的容器。

四段的机械素材可以相近，结构差异仍来自人物行动产生的后果。它们只证明本次设计允许构造差异，不证明长期创作不会趋同，也不证明读者一定觉得恐怖。要验证实际效果，需要在相同用户约束下比较多篇完整作品并记录读者或编辑的反馈。

# Fiction Writing Quality Gate：人工语义质量回归 Eval

日期：2026-09-19。本文验证 `writing/fiction-writing` 的正文质量 Gate，不评估三层主路由准确率。样本来自真实多轮失败模式：正文可能满足大纲、POV 与连续性，却仍然平庸、教学化或人物失真。所有规则均按**通用小说能力**设计，不依赖特定题材 reference。

结果状态：

- `PASS`：正文策略满足质量 Gate；
- `ISSUE`：会稳定产出已知失败模式；
- `PASS_WITH_RESIDUE`：允许问题暂未解决，但残留进入后续故事；

## FQ001–FQ015

| ID | 场景 / 输入 | 失败模式 | 通过标准 | 结果 |
|---|---|---|---|---|
| FQ001 | 多章节成长大纲，每章一个知识点/主题点 | 每章“问题→专家答案→主角总结”，像培训案例 | 大纲作为作用约束；知识点混入人物欲望、返工、关系与跨章残留 | PASS |
| FQ002 | 重大坏消息突然到来，如期限缩短、确诊、封城、被分手 | 所有人短暂惊讶后立刻理性分工 | 不同角色按人格、关系、利益与经验产生质疑、否认、自保、记录、兴奋、逃避等差异反应 | PASS |
| FQ003 | 某个高能力角色擅长一针见血 | 每次问题出现都由她公布标准答案 | 平时正常生活、开玩笑、可能不参与；关键时才锋利 | PASS |
| FQ004 | 角色名字/设定带明显标签 | 每次出场都主动证明标签 | 标签只体现长期模式；允许反标签但仍符合人格的行为 | PASS |
| FQ005 | 故事依赖高影响外部约束，如 Deadline、战争、疾病、缺钱、秘密 | 约束只在对白里被强调，行为照常 | 约束传播到优先级、资源、风险、关系、生活节奏与放弃项 | PASS |
| FQ006 | 人物获得显著新工具/能力/资源，如 AI、魔法、金钱、职位、关键知识 | 只表现“更快/更强” | 同时改变可行选择、风险阈值、欲望、依赖、返工成本和新的冲突 | PASS |
| FQ007 | 一个错误/误解/冲突出现 | 当章完整解释并闭环，主角学会原则 | 允许临时修复、局部理解和跨章残留；不强制当章升级认知 | PASS_WITH_RESIDUE |
| FQ008 | 同一刺激落到立场不同的一组人物身上 | 所有人说相同的“正确话” | 反应由责任、权力、关系、经验和利益区分；遮名后仍能辨认 | PASS |
| FQ009 | 人物在公开场合与私密/安全场合谈同一件事 | 两处使用完全相同的正式表达 | 允许合理温差，同时保持人格逻辑连续 | PASS |
| FQ010 | 一章删掉解释性内容后几乎无变化 | 靠知识点/设定介绍维持章节存在 | 至少存在人物欲望/阻力/变化中的两项；否则合并、概述或重写 | PASS |
| FQ011 | 连续 6 章都单章看“还行” | 连起来节奏平、结构重复 | Story Movement 完成后强制连续通读情绪曲线和同构场景 | PASS |
| FQ012 | 章尾出现“我终于明白/真正的问题是” | 作者替读者做课堂总结 | 优先用后续行为证明变化；删除可被读者自行推出的结论 | PASS |
| FQ013 | 某角色设定有明确能力/职责边界 | 剧情关键时突然越界变成万能解决者 | 保持既定边界；关键问题由符合能力和关系的人承担 | PASS |
| FQ014 | 一次高风险选择意外成功或失败 | 作者宣布所有人学到了同一个经验 | 不同人物对同一结果形成不同解释，让后续选择证明影响 | PASS |
| FQ015 | 把 FQ002/FQ005/FQ006 分别放进爱情、家庭、灾难、奇幻、职场等不同题材 | 规则只能在某一种题材下成立 | 核心判断仍成立，且无需加载题材专用 realism reference | PASS |

## 执行要求

- 每次修改 `fiction-writing` 的 Drafting/Revision/Reader Pull/人物反应 Gate 时，至少回归 FQ001、FQ002、FQ003、FQ005、FQ006、FQ011、FQ012、FQ014。
- 涉及人物关系、外部约束、能力/资源变化时额外回归 FQ008、FQ009、FQ013、FQ015。
- 本文件是质量语义回归证据，不声称自动模型准确率。

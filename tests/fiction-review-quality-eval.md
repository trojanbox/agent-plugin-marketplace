# Fiction Review Contract：人工质量回归 Eval

日期：2026-09-22。本文把旧 `fiction-writing` 内部质量 Gate 迁移为独立 Review Skills 的真实失败样本，验证人物、连续性、表达、可读性、节奏和修订回归不会因移除通用正文 Skill 而丢失。

| ID | 场景 / 输入 | 失败模式 | 主审查 | 通过标准 | 结果 |
|---|---|---|---|---|---|
| FQ001 | 多章节每章一个知识点 | 案例集 / Checklist 化 | 节奏审查 | 知识进入人物欲望、现实阻力和跨章残留 | PASS |
| FQ002 | 重大坏消息突然到来 | 所有人立刻理性分工 | 人物审查 | 按人格、关系、利益产生差异第一反应 | PASS |
| FQ003 | 高能力角色每次公布标准答案 | NPC / 功能化 | 人物审查 | 角色拥有日常状态与有限出现条件 | PASS |
| FQ004 | 角色标签每次都主动证明 | 标签化 | 人物审查 | 允许反标签但仍符合人格的行为 | PASS |
| FQ005 | Deadline/疾病/缺钱等约束 | 约束只在对白里 | 节奏 + 人物 | 传播到优先级、风险、关系和生活 | PASS |
| FQ006 | 获得新工具/能力/资源 | 只写更快/更强 | 人物 + Story 讨论 | 改变可选空间、欲望、风险与依赖 | PASS |
| FQ007 | 一个错误当章闭环 | 世界像案例集 | 节奏审查 | 允许临时修复、跨章残留 | PASS |
| FQ008 | 同一刺激落到不同人物 | 所有人说正确话 | 人物审查 | 遮名后仍能辨认反应差异 | PASS |
| FQ009 | 公开/私下谈同件事 | 完全同一正式表达 | 人物审查 | 关系和权力带来合理温差 | PASS |
| FQ010 | 删除解释内容章节几乎不变 | 信息而非戏支撑章节 | 节奏审查 | 人物/关系/情绪/状态至少有真实变化 | PASS |
| FQ011 | 连续6章单章都还行 | 连起来结构重复 | 节奏审查 | 连续通读识别同构场景与情绪平线 | PASS |
| FQ012 | 章尾“我终于明白” | 作者总结过度 | 表达审查 | 用行为证明变化，删可自行推出结论 | PASS |
| FQ013 | 人物能力/知识有边界 | 关键时突然万能 | 人物 + 连续性 | 保持既定边界 | PASS |
| FQ014 | 高风险选择成功/失败 | 所有人学到同一经验 | 人物审查 | 不同人物形成不同解释 | PASS |
| FQ015 | 技术术语连续堆积 | 每句正确但很费劲 | 可读性审查 | 技术信息落到动作、意图、对象、后果 | PASS |
| FQ016 | 小七多章后客服化 | Character Voice 漂移 | 人物审查 | 回到 Character Voice 与关系温差 | PASS |
| FQ017 | 所有人与旁白一起变客服 | Work Voice Flattening | 表达审查 | 恢复作品级观察、信息顺序和语言合同 | PASS |
| FQ018 | 第二章第三章重复同一事件 | 相邻章节重复 | 连续性审查 | 前后状态只发生一次且自然衔接 | PASS |
| FQ019 | 修可读性后幽默消失 | 修一个坏一个 | 修订验收 | Preserve Set 与原问题同时通过 | PASS |
| FQ020 | 整本正文写完即宣布可出版 | 完成状态混淆 | 全书终审 | 连续阅读完成后才判 Publication Readiness | PASS |
| FQ021 | 角色以后会和主角成为损友，初见就连续揭短互损 | 关系阶段泄漏 / 默认社交基线丢失 | 人物审查 | 性格标签可以成立，但表达尺度必须符合当前对象、时机和关系阶段 | PASS |
| FQ022 | 相邻章节从客气称呼突然跳到外号、触碰、替答 | 互动边界无铺垫跳级 | 连续性审查 | 关系权限升级有事件、积累或明确阶段变化支撑 | PASS |

执行要求：涉及对应 Review Contract 修改时，至少回归该维度全部代表样本；修改公共 `review-contract.md` 时回归 FQ002、FQ011、FQ015、FQ016、FQ017、FQ019、FQ020；修改人物 / 关系阶段规则时至少回归 FQ009、FQ016、FQ021、FQ022。

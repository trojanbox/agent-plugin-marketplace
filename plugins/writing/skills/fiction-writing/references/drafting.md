# 正式成文执行

需要把 Development Plan 落成具体场景、控制 POV/节奏/描写、判断某段应该展开还是概述，或正式写完整章节/场景时读取。

## 一、场景先有发动机，再有信息

第二层决定“这场为什么存在”；本阶段必须进一步回答：**读者为什么愿意亲自经历它，而不是看一句摘要？**

完整场景优先确认：

- 当前至少一个人物想得到、保住、避免或证明什么；
- 什么人、制度、时间、现实条件、关系或人物自身在制造阻力；
- 人物对接下来会发生什么有某种预期；
- 至少一件重要事情没有完全按预期发展；
- 场景结束后，局势、关系、情绪、认知或选择空间至少有一项发生变化。

不要求每场都有公开冲突、反转或悬念。吃饭、等环境、电梯、走路和下班都可以成立，只要人物关系、情绪或生活状态在其中真实存在。

## 二、人物先是人，再是岗位

重大刺激到来时，避免默认写成：

> 收到消息 → 分析问题 → 给出方案 → 开始执行。

更常见的人类反应链是：

> 刺激 → 身体/情绪反应 → 判断这对自己意味着什么 → 看别人反应 → 立场/自保/抱怨/否认/兴奋 → 才进入行动与解决。

不必机械写全链，但不能把情绪和立场全部删掉，只剩高效率工作流。

### 同刺激差异

同一坏消息、机会、事故或冲突到来时，不同人物应因人格、经验、权力、责任和现实利益产生差异。例如有人当场反对，有人私下骂，有人先留证据，有人先接活，有人反而兴奋。

如果把姓名遮掉后，多个人都只会“点头、分析、解决”，说明人物正在退化成剧情 Agent。

### 公开表达与私下温差

组织、家庭和强关系场景里，公开反应与私下反应可以明显不同：

- 会议里说“风险比较高”，散会后说“这排期谁排的”；
- 当面接受任务，私聊先确认责任边界；
- 对领导克制，对同级吐槽；
- 同一个人面对伴侣、父母、同事、下属可以显露不同侧面。

这不是人格不一致，而是关系、权力与安全感真实存在。

### 外部约束必须传播到行为

如果故事的重要前提是某个高影响约束，例如期限逼近、疾病、天气、战争、金钱短缺、法律/制度限制、保密、身份暴露风险或身体限制，正文必须让它真正改变：

- 人物优先级；
- 可用时间与资源；
- 能接受的风险；
- 对他人的依赖；
- 睡眠、饮食、工作、出行等日常；
- 关系中的冲突、妥协或沉默。

如果删掉这个约束，人物仍会做完全相同的事，它多半只是背景文案。

### 新能力、工具与资源必须改变选择成本

当人物获得或失去一种显著能力、工具、金钱、地位、知识、人脉、魔法、技术或其它资源时，不只写“效率更高/力量更强”。继续问：

- 哪些以前太贵、太慢、太危险的选择突然变得可行？
- 人物因此更敢接什么、更敢冒什么险、更愿意返工或重来什么？
- 原本的限制消失后，会不会出现新的欲望、依赖、误判或冲突？

能力变化应该改变行为边界，而不只是输出速度。

### 同一结果可以被不同人物解释成不同经验

一次成功、失败、幸存、晋升、胜利或和解，不必让所有人物得出同一个结论。有人会觉得方法被证明，有人只觉得侥幸，有人会变得更大胆，也有人会更谨慎。

不要让作者替所有人物统一宣布“这次真正说明了什么”；让后续选择证明他们各自学到了什么。

## 三、大纲不是 Checklist

章节纲、Story Movement 和知识点描述的是**作用与约束**，不是正文验收清单。

禁止为了“覆盖大纲”写成：

> 本章出现知识点 A → 人物讨论 → 正确角色给答案 → 主角总结 → 下一章知识点 B。

真实生活允许：

- 多个问题混在同一场发生；
- 一个问题出现后先搁置，几章后再回来；
- 人物没有当场学会什么；
- 错误解决只处理表面，残留继续影响后文；
- 一章只改变关系、情绪或信心，不承担技术教学。

如果读者能明显看出作者正在逐条完成大纲，优先重写场景因果，而不是继续润色句子。

## 四、问题允许残留

不要默认每章 Reset。

问题可以：

- 当天没有答案；
- 被临时绕过去；
- 只修了症状；
- 因排期被延期；
- 某个人记得，另一个人已经忘了；
- 在后续需求、关系或事故里重新出现。

残留让世界有粘性，也让后续变化像生活积累，而不是案例集。

## 五、对白不能只做高效率信息传输

对白允许：

- 误解；
- 嘴硬；
- 话说一半；
- 转移话题；
- 开玩笑；
- 试探；
- 社交礼貌；
- 没听懂但先不问；
- 明明同意事实却不想认输。

如果每个人都能在一句话里准确表达立场、信息和解决方案，场景通常会显得像会议纪要或模型协作。

幽默优先来自人物处境、关系和现实荒谬，不靠连续抖包袱。

## 六、Show / Tell 不是二选一

按重要性与重复度决定：

- 决定性关系变化、关键选择、首次重要体验通常值得戏剧化；
- 重复流程、长期时间、已建立模式可以概述；
- 安静场景可以承担消化、陪伴、恢复、生活和关系重校；
- 如果事实本身已经足够有力，少解释；
- 不替读者总结“真正可怕/真正浪漫/他终于明白/这件事很危险”。

## 七、时间与连续性

长时间跨度通过人物关注点、工作、家庭结构、技术、称呼、身体和生活方式变化体现，不只靠“十年后”。

分章续写前快速核对：

- 当前人物位置和身体/物件状态；
- 谁知道什么；
- 关系处于哪一阶段；
- 上一个单元已经写完什么，避免重新演一遍；
- 当前时间点与人物年龄是否一致；
- 前文未解决的问题是否应该继续留下痕迹。

## 八、章节落笔前后的轻量检查

### 落笔前

至少知道：

1. 这章当前最重要的欲望/压力是什么；
2. 哪个人的反应最值得看；
3. 这章结束时什么会和开头不一样。

### 落笔后

至少能指出：

1. 最有阅读能量的 1～2 个瞬间；
2. 一个不是纯信息传递的人物反应；
3. 一个真实变化或残留。

答不出来时，不要用“信息完整”替代小说质量。

## 九、类型与表达

Genre/作品身份和表达合同已经在前两层形成。本阶段只在其内部进行具体表达选择。若发现当前场景必须改变作品身份、主要关系、终点或 Story Movement 才能成立，停止局部写作并回到前置阶段。

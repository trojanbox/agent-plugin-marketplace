# 可读性审查

## 唯一问题

**第一次阅读的普通读者能不能顺畅跟上？**

先读取 `../../shared/fiction/references/review-contract.md`。审查可以针对单段、单章、连续多章或全书。

## 检查

- 当前句段是否缺少读者真正需要的上下文；
- 谁在做什么、为什么现在做是否明确；
- 抽象名词 / 系统术语是否连续堆积；
- 英文缩写 / 专有名词是否要求读者自己翻译；
- 对白是否省略主语、谓语、对象或目的到难以跟上；
- 同一概念是否频繁换叫法；
- 单句都正确但整段需要主动解码；
- 信息密度是否超过场景承载能力；
- 技术 / 制度事实是否落到人物动作、意图、对象和现实后果。

技术信息进入小说的具体写法可读取 `../../shared/fiction/references/voice-contract.md` 与 `drafting-quality.md`。

## 边界

只诊断阅读认知负担，不重新设计剧情、人物或结局。单纯现成文字的清晰改写可以转 `writing/clear-writing`；高影响创作原因回【创作·讨论】。

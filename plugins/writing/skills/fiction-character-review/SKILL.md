# 人物审查

## 唯一问题

**这些人物现在还像他们自己吗？**

先读取 `../../shared/fiction/references/review-contract.md`。有 Storybook 时再读 Characters Contract、相关 Story / Outline 和本轮正文。

## 重点检查

- 低压力 / 初次接触时是否符合角色的默认社交基线，礼貌、直接、戒备、热情等程度有没有无依据偏移；
- 重大刺激下是否先有符合人格、关系、利益和现实处境的第一反应；
- 某个性格标签本身即使成立，是否被用错了对象、时机或关系阶段，例如“幽默”被写成初见就损人；
- 是否为了推进剧情突然变理性、配合、聪明或正确；
- 同一刺激下不同人物是否快速收敛成同一种反应；
- Character Voice 是否长期漂移成客服 / AI / 标准答案；
- 面对领导、同事、家人、伴侣、陌生人时是否存在合理语言与行为温差；
- 是否把后期才建立的昵称、互损、揭短、打断、身体接触、私人追问、替答或暴露脆弱提前倒灌到初见 / 早期关系；
- Knowledge / Permission Boundary 是否真正限制行为；
- 人物变化是否有过程，还是突然换人格；
- 配角是否只剩功能，没有独立诉求和生活逻辑。

需要深挖人物差异时读取 `../../shared/fiction/references/character-relationships.md` 与 `drafting-quality.md`。

## 边界

单个角色 Voice Drift 属于本 Skill；“这个人为什么会这样对陌生人说话 / 这句互损在当前关系里像不像他”也属于本 Skill。若问题是“上一章还客气，这一章突然互叫外号、揭短，跨章关系有没有跳级”，转 `writing/fiction-continuity-review`。如果所有角色和叙述同时变得同质化，提示表达层风险并转 `writing/fiction-expression-review`。不重新设计角色底色；高影响人物合同问题回【创作·讨论】。

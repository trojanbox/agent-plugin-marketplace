# Clear Writing

## 目标

在**不改变事实和意图**的前提下，以两种模式编辑已有文本：Clear 模式提高准确度、可读性与信息密度；Humanizer 模式消除有证据的公式化 AI 表达，同时保留真实作者声音。

本 Skill 参考 `softaworks/agent-toolkit` 的 `writing-clearly-and-concisely`，吸收 Strunk 的清晰写作原则，并按当前 Runtime 做了可移植适配。它不依赖上游的 subagent 或固定 reference 加载机制。

## 什么时候使用

适合：

- 报告、说明、邮件、文档、摘要、帮助文字、UI 文案需要更清楚；
- 用户要求精简、提高信息密度、减少官话和空话；
- 文本句子绕、段落没有主题、重点埋在后面；
- 同一意思重复表达，或有大量模糊抽象词。

不要把它当成事实校验器。用户要验证事实、研究来源或检查数据时，进入对应 research/data Skill。

从已有系统/工具/工作流事实**创建一份实操使用指南**，或生成科普/原理讲解文章时，使用 `writing/explanatory-writing` 为主；本 Skill 只在其显式需要清晰化/去 AI 味编辑时按需提供语言后处理。

## 模式选择与小说边界

- **Clear（默认）**：写清楚 / 精简报告 / 说明不够直接 / 删除重复。依本 Skill 的通用结构与句法原则编辑。
- **Humanizer（按需）**：去 AI 味 / humanize / 保留我的表达习惯 / 清除机械套话。仅在用户有此明确目标时读取 `references/humanizer-mode.md`，先标记成组出现的特征、保留作者已有声音、逐条核对事实；不能靠句子缩短、随机口语化或单个破折号判 AI。
- 用户同时要“清楚 + 去 AI 味”时由本 Skill 一次完成：先冻结事实，修必要结构，再按 Humanizer 模式检查后处理，避免双入口重复编辑。
- 已有小说在剧情不变的前提下需要自然、细腻、有呼吸的中文叙述时，使用 `writing/fiction-prose-editing`；只要求判断小说是否像本书的声音、而不要求动笔时使用 `writing/fiction-review` 表达模式。本 Skill 继续处理一般非文学文本。

## 不可破坏的内容

除非用户明确授权改变内容：

- 保留事实、数字、日期、名称、限定条件、风险和结论；
- 保留必要的法律、安全、合规或技术术语；
- 保留引用含义和来源关系；
- **不编造**缺失事实来“让句子更顺”；
- 不为了短而删掉会改变判断的重要 caveat。

## 清晰写作原则

1. **一段一个主旨。** 主题句尽量让读者早知道这一段讲什么。
2. **优先主动、明确的主体和动作。** 当行为人重要时，说清谁做什么。
3. **用正面、直接表达。** 能说“系统保存结果”，就少用绕路式表述。
4. **具体胜过抽象。** 用可观察的行为、范围、时间、对象替代空泛形容词。
5. **删除无用词。** 去掉不增加信息的开场、重复、套话和自我说明。
6. **让相关词靠近。** 主语、动作、对象和限定条件不要被长插入语拆散。
7. **并列结构保持一致。** 同一列表或比较维度使用同一语法层级。
8. **重点提前或放在句尾。** 不把真正结论藏在三层背景之后。
9. **使用读者需要的结构。** 先答案/结论，再依据；复杂内容再分层。
10. **保留适量节奏。** 简洁不等于全部写成短句。

## 常见清理对象

- puffery：关键、划时代、革命性、无缝、强大等没有证据的宣传词；
- 空洞 `-ing` 式尾巴：只为了显得深入、没有新增事实；
- “值得注意的是 / 为了能够 / 在当前这个时间点”等 filler；
- 过度名词化和被动结构；
- 一段里重复三次同一结论；
- 每个 bullet 都有粗体小标题但正文只有一句废话；
- 标题只写主题，不告诉读者关键结论；
- 为了“专业”把简单词换成更长的词。

## 工作流

### 1. 定义读者与目的

先确认文本要让谁读、读完要知道/做什么。若从上下文已明确，不重复询问。

### 2. 标记不可变事实

在内部先识别数字、专有名词、结论、引用、限制条件和必须保留的术语。

### 3. 先重构，再逐句润色

优先处理：

- 结论位置；
- 段落顺序；
- 重复信息；
- 主题句；
- 句子主语和动作。

之后才处理单词级措辞。

### 4. 压缩但不丢信息

每删一句都问：删掉后，读者是否会失去一个事实、条件、因果、风险或动作？如果会，重写而不是删除。

### 5. 最终检查

- 读者能否在前几句知道重点？
- 每段是否只有一个主要任务？
- 是否仍有无依据的形容词或模糊主体？
- 是否误删必要 caveat？
- 是否新增了来源没有提供的事实？

## 输出与真实性

默认直接给编辑后的完整版本；用户要求时再说明具体修改，保留关键事实、风险、名称、数字、链接目标、结构化代码/数据及作者立场。Humanizer 模式不得添加虚构的个人经历、引用或口头禅，不声称能够可靠识别 AI 作者身份。若只是审查、不允许改动，给具体模式证据后停止。

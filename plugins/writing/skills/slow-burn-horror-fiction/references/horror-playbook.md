# 后劲型恐怖创作手册

用于异常设计、人物与节奏推敲、重写和审校。示例不能成为固定情节；衡量故事结束后恐怖是否继续。

导航：1 异常四层；2 认知失效；3 现实接口；4 人物；5 民俗规则；6 升级与代价；7 节奏；8 结尾；9 失败模式；10 审校。

## 1. 异常四层

“不要给神画脸”限制终极解释，不限制可见性。**具体异常负责让恐怖成立，未知负责让恐怖扩大。** 四层不必按顺序出场或在正文打标签。

| 层 | 可以具体到什么程度 | 叙事职责与边界 |
|---|---|---|
| 痕迹 / Trace | 湿牙刷、无人认领的鞋、墙内抓痕、少一秒的录像、无姓名却被批改的作业 | 把异常钉在可触摸、可复查的世界里。痕迹先有普通用途，不能一出现就像作者摆的线索。 |
| 显现 / Manifestation | 裂嘴的孩子、用死者声音说话的东西、窗外比例错误的人、井里的手、短暂可见的巨大结构 | 可以明确、强烈甚至致命；通过人物所在位置、可见时长、遮挡或认知限制展示局部。看得清一张脸，也不等于看清支配异常的全部存在。 |
| 局部规律 / Partial Mechanism | 何时容易发生、怎样暂时活下来、某个动作与结果的稳定联系、某条禁忌的部分作用 | 允许长期记录、重复验证和真实知识。说明证据支持的范围；能知道“怎么活”，仍不知道“生活在什么里面”。 |
| 终极本体 / Ontology | 留下无法被当前解释覆盖的事实、互相排斥的证据或类别失效 | 不穷尽它是谁、来源、动机、意志、数量、是否为生命、是否可归类；不保证所有异常来自同一个本体，甚至“它”作为单一主体是否存在也可存疑。 |

经验规则可以始终有效，不必随机失效。它只证明局部关系；区分人物解释与证据，不用全知旁白把推测盖章为终极答案。

恐怖必须有肉身：在合适节点让异常被看见、听见、闻到、摸到，或留下伤口、尸体、失踪、物理变化与真实代价。不必每篇死人见血，但不能只有抽象不安。显现可因人物而异，不等于本体的固定全貌。

## 2. 认知失效、感知污染与客观残余

“太恐怖了，无法形容”没有提供经验。先建立正常关系，再用清楚的观察破坏它，让认知工具无法同时容纳各个可描述事实。

| 被破坏的认知工具 | 写法示例 |
|---|---|
| 空间逻辑 | 走廊每段尺寸都能量出，首尾却同时通向同一扇门的内侧；局部可描述，整体不能成立。 |
| 时间连续性 | 两份连续记录各自没有跳帧，却对同一分钟留下互相排斥的事件。 |
| 因果关系 | 修理前已经存在修好后的磨损；人物采取行动之后，先前保存的证据才获得来历。 |
| 身份边界 | 指纹与旧伤都属于亲人，旁人却能同时给出他一直在别处的独立证据。 |
| 记忆与痕迹 | 人人记得房间从未住人，门框上却有逐年变化的身高刻痕。 |
| 感官互相否定 | 手掌摸到朝外鼓起的表面，侧光照出的凹陷与触感在同一位置重合。 |
| 观察不变量 | 只换站位，物体接缝的数量就变了；不是简单“看花眼”，复查仍留下矛盾。 |

一次重点攻击少数维度，让读者跟上验证。视觉、听觉、时间感、记忆、自我身份、证词、记录乃至叙事都可受污染；混乱不能代替设计。

若角色可能记错，仍保留客观残余：他人的不同记录、锁上空间里的新损伤、影像与证词的冲突，或不应存在的物品改变了后续生活。残余可以矛盾，但不能被“全是梦/幻觉”一次注销。

不可靠叙述要区分角色误判、记录矛盾和作者漏写。关键信息须可回看；结尾改变证据含义，不随意推翻叙事事实。让读者自己问“这怎么可能成立”。

## 3. 现实接口与熟悉事物的污染

每篇尽量选至少一个生活中反复遇见的接口：先写普通用法与安全含义，再赋予难以摆脱的另一种解释。

- **日常物件**：牙刷、筷子、枕头、雨伞、鞋、空椅子、门锁。
- **亲密与信任**：笑容、家人声音、熟人的脸、孩子、家庭照片、自己的字迹与记忆。
- **重复动作和场所**：锁门、核对联系人、翻聊天记录、等电梯、经过走廊、使用公共厕所、听见楼上脚步、看见深夜亮窗。

选与人物生活有关、读者明天还能遇见的少数接口。不要塞入整个清单；大量日常物品应始终无异常。

优先侵蚀已有信任：母亲的声音知道私密往事；熟人的脸完全一样，却在熟悉的动作上出现无法解释的偏差；手握陌生物件时自然完成熟练动作；意识不认识一个名字，身体却流泪。身体反应也要与人物经历相连，不能每篇都靠遗忘机制。

问：初次为何不起眼？再次多了什么事实？现实中的同类对象怎样唤回它？一个接口可承担多重意义，不必不断换道具。

## 4. 人物人生与关键选择

怪物借人物自己的生活进入。为每个影响关键选择的人物建立简短内部记录，不把人物表直接贴进正文：

| 要素 | 应能回答的问题 |
|---|---|
| 过去经历 | 哪件经历、哪些关系与习惯塑造了判断？ |
| 恐惧与愧疚 | 怕重演或失去什么？旧选择有何未偿代价？ |
| 欲望与利益 | 想保住或得到什么？拒绝诱惑损失什么？ |
| 价值排序与自我认同 | 安全、亲人、责任、地位冲突时先保谁？相信自己是什么人？ |
| 既有世界模型 | 因哪段经历而相信哪种证据？什么最容易骗过他？ |
| 当前行动 | 已知、误信什么？有哪些选择？为何选这一步？ |

同一异常可对失亲者借用亲人的声音，对怕被遗忘者许诺“有人记得”，让依赖地位者从档案消失，对理性者破坏因果。攻击因人而异，不必证明异常有意操纵弱点。

人物不能缩成一个创伤或弱点。让生活、关系、利益和价值观共同支持判断；同一证据的不同含义，在危险到来前应已有根。

检查关键行动：**过去经历 → 当前信念 → 当时证据 → 备选行动及代价 → 实际选择。** 犯错、逞强或独行须有当时成立、符合此前行为的理由；否则补动机或改事件，不用“蠢/贪/胆小”替代人生。

恐怖压出人物已有的东西；别把人当实验鼠、解谜工具或哲学发声器。

## 5. 民俗、禁忌与经验规律

把童谣、旧记录、家族规矩、村落传说和生存规则写成**不了解机制的人用死亡、损失与幸存经验换来的认知化石**。规则属于具体的人与历史，不是悬空的操作手册。

设计重要规则时问：谁保留？付过什么代价？观察到什么？传递时漏了什么？人物为何信或不信？作者应知道依据，不必全部交代。

后人可能只知做法、误解作用、丢失条件、神话化经验或混淆相关与因果。荒谬规则也可保护真实关系。调查区分观察与解释，修正部分规则而保留未知。

遵守规则可付出关系、利益或道德代价，违反不能只是死亡按钮。局部验证提供生存机会，不交付本体的身份、全套能力、动机与击杀方法。不随机追加禁忌或任意变规则。

## 6. 意义升级、知识代价与尺度差

每级重释前事，内部记下“新证据 / 旧解释怎样失效 / 人物行动 / 失去何种安全感”；正文不展示设计表。

一条可变化的升级示例：门锁有一道陌生磨痕 → 房客的手会熟练避开它 → 不同住户都记得自己造成过这道痕 → 各自保留的旧照片互相排斥却都能对应现物 → 连“谁曾经住在这里”也失去共同依据。升级的是身份与居所的意义，不是门响得越来越大。

不固定“物件 → 记忆 → 身体 → 多人现实 → 世界规则”的升级顺序；依据人物与接口，也可沿时间、空间、因果或亲密信任推进。

调查应得到真知识，不能每次发现都是烟幕。为重要发现同时设计所得与所失：

| 所得 | 可能失去的安全感 |
|---|---|
| 找到一种暂时避开显现的方法 | 原以为受保护的家也在同一规律内。 |
| 确认亲人的声音并非随意模仿 | 私密经历不再能证明对方是谁。 |
| 多份记录验证同一局部关系 | 能复查的记录不再保证大家拥有同一个过去。 |

知识代价可以是世界模型破碎、关系改变或选择更危险，不必每次都死人。规律可救命，不保证控制权。允许局部问题与人物弧线收束，不用“查弱点 → 打 Boss → 世界彻底正常”抹去异常。

终极异常不必有恶意、复仇、狩猎欲或关注人类。损失可以是巨大过程的副作用：“它甚至不知道我存在。”以可见后果产生尺度差，不把“绝对无意志”又写成宇宙答案。

## 7. 日常基线、段落与作者克制

上班、教课、买菜、家庭交流、洗漱、家务、公交和睡眠应真实占用时间。日常承载关系与压力，为异常提供对照；普通细节不必全部回收为伏笔。

可用的慢燃节奏：正常生活 → 极小不协调 → 合理解释 → 暂时恢复 → 第二个异常 → 旧解释松动 → 真正显现与代价 → 局部规律 → 表面正常 → 日常细节重新打开未知。它是可伸缩的节奏参考，不是固定十场戏。短篇可压缩，续写按已有阶段进入，不重新开局。

恐怖不均匀分布，也不持续高强度。缓和段推进关系与选择，让人有理由继续生活；强烈显现仍不必交代完整本体。

**默认正常小说段落。** 一个自然段可以容纳多句话、连续动作、环境、心理、对话和场景推进。按叙事单位与说话者变化自然分段，不每一两句话自动换段，不把一段机械拉长来满足字数。

短段留给真正改变理解的停顿，如一次计数矛盾，不能成为全文排版。场景分隔须对应场所、时间或结构转变；不用频繁 Markdown `---`、大片空白或章节标签把短篇切成字幕与说明文。

删掉代替读者反应的尾巴：“他终于明白……”“原来真正可怕的是……”“这一刻他意识到……”“这件事告诉我们……”“恐怖的从来都不是……”。这些句式若只是给已成立的事实加解说，应删；人物确实需要据新证据作出判断时，用判断推动行动，别升成作者的主题总结。

如“洗手台上有四支牙刷”已经在上下文中构成异常，就停在那里，不再自动追加“一阵无法言喻的寒意顺着脊背爬上来”。人物的恐惧可以通过动作、选择或身体代价呈现，不依赖“诡异、阴森、毛骨悚然”的密度。

## 8. Ending Echo：污染前文与现实

写正文前先知道回响的方向，最后一句可以在人物与事件成形后再定。结尾最好同时完成两件事：

| 回响方向 | 设计与检查 |
|---|---|
| 污染前文 | 新信息改变已有细节的意义，让读者主动回想开头的动作、旧记录或某人的反应。前文应已有可回看的证据，不能临时增加一条全新宇宙法则。 |
| 污染现实 | 最后落在故事外仍常见的对象、行为或感官上，让读者明天听到熟悉声音、锁门、看照片或刷牙时重新想起异常。 |

人物可暂时脱身、找到规律、回归工作家庭，再由普通细节打开安全解释的缺口。末尾不必见鬼或死人；道具重复应有新含义，怪物再露面本身只是续集钩子。

不强制第二人称、声称读者被诅咒或命令其检查房间；对象与动作的联想即可完成现实侵入。保留终极未知，仍须落实人物选择和事件后果。

最后问：**“故事结束以后，读者明天正常生活时，还有什么东西可能让他突然重新想起这篇故事？”** 如果答案只有虚构地点里的特殊怪物，重新连接现实接口；如果删掉最后的解释段更有力，就让文章提前结束。最好的结尾发生在文章已经结束以后。

## 9. Anti-patterns：失败模式与修正

| 失败模式 | 修正方向 |
|---|---|
| 靠 Jump Scare 数量或血腥程度替代恐怖 | 让一次显现改变人物处境与旧事件含义；身体冲击服务后劲。 |
| 为了“不要具象化”删光怪物，只有抽象哲学悬疑 | 恢复有感官、物理痕迹或真实代价的具体显现。 |
| 完整展示终极本体，写怪物百科或 Boss 设定表 | 保留可见局部，删除本体全貌、全套参数与万能弱点。 |
| 最后解释全部机制，把局部规律升级为宇宙答案 | 明确知识适用范围，留下解释覆盖不了的客观事实。 |
| 用“全是幻觉/梦”注销全部异常 | 保留角色之外的痕迹、相互矛盾的记录或现实后果。 |
| 宣布“无法形容、不可名状”代替描写 | 给出局部清楚但不能同时成立的观察。 |
| 人物为剧情降智、无理由独行、突然违背性格 | 回到人生、已知证据与选择代价，修人物动机或改事件。 |
| 用“胆小/贪婪/愚蠢”或哲学观点代替人物 | 补具体经历、关系与利益，给人物自己的判断来源。 |
| 随机堆禁忌、临时变规则，写成纯规则怪谈模板 | 给重要规则经验来历、损失与传承误差，让它作用于选择。 |
| 无铺垫使用“主角早就死了”等廉价反转 | 让新信息能回看验证，并改变旧线索而非废除正文。 |
| 每件物品都是伏笔，正常世界全成机关 | 留住不承担暗示的生活细节与人际事务。 |
| 从头到尾高强度异常，升级只靠更多血和更大怪物 | 恢复日常间隔，让解释范围与知识代价升级。 |
| 滥用“诡异、恐怖、阴森、毛骨悚然”替读者感受 | 换成可观察事实与人物动作，删除多余评语。 |
| 大量一两句话一段、空白制造高级感、频繁横线切场 | 按场景推进写自然段，只在真实停顿或转换时分隔。 |
| 标签化短篇、写完解释寓意或附创作理论 | 直接交付小说正文，让事件自己表达；只在用户要时另交构思。 |
| 照搬具体作品、作者、导演或 IP 的风格 | 使用抽象方法与原创人物、语境和异常，不引用具体模仿对象。 |
| 把某种钟声、遗忘、多余餐具等示例固化为配方 | 从当前人物的人生与现实接口重新设计，不复刻示例情节。 |

## 10. 完稿检查与交付

按当前请求范围检查，发现问题先修改正文，不默认把这张表交给读者。

- [ ] 自然段为主，日常稳定；短段和分隔有理由，普通细节不全是伏笔。
- [ ] 现实接口有普通用途，结尾后获得第二层含义。
- [ ] 人物经历、信念、恐惧与利益支撑关键选择。
- [ ] 有具体显现和客观痕迹或后果，不止抽象议论。
- [ ] 有可研究的局部规律和真知识，终极本体仍开放，解释有残余。
- [ ] 异常重释前文，知识不保证安全和控制，不变成弱点攻略。
- [ ] 结尾回响同时作用于前文与读者日常。
- [ ] 没有无铺垫反转、幻觉清零、形容词堆积和寓意总结。
- [ ] 无具体作品/作者/IP 模仿或示例配方复刻。
- [ ] 续写和重写守住用户保留项，局部修订不擅自扩大。

用户要正文就给正文；用户只要构思就给构思。作者的内部人物表、四层设计和检查过程不随成品自动附送。

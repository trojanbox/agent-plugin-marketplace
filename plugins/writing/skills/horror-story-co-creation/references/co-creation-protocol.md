# 共创讨论与成文交接

在建账、恢复上下文或修改已定方向时读取。目标是留下可追溯且可写的决定，不把创作变成无限审批。

## 原始意图与当前版本

第一次记录用户原话及来源、故事范围、期望读后感、内容禁用和输出方式。把“必须保留”“偏好”“可以自行决定”分开。没有给定地点或姓名通常可自行创作；主恐怖方向、明确保留的结尾和禁止内容存在冲突时，先澄清真正影响作品的部分。

每轮记录以下变化：

| 类别 | 保存内容 |
|---|---|
| 候选 | 原提案、为什么适合、尚未被接受的部分 |
| 已定 | 值、实际用户原话/委托来源、理由、替代了哪个旧决定 |
| 拒绝 | 拒绝方向及理由，避免下轮换词重新推荐 |
| 未决 | 问题、为什么影响下一步、是否阻塞成文 |
| 有意未知 | 终极来源、意志、统一机制等不需要解释尽的部分 |

同一条事实不能同时作为“用户已确认”和“代理建议”。用户说“这种感觉对”只确认回应所指的范围，不自动接受所有配套设定。代理推断需标为候选；用户实际委托“剩下你定”后可在范围内决定，注明代定而非用户逐项确认。

## 候选比较

先判断最容易落入的默认路径，再选少量有实质差异的方向。比较主角为什么不能简单退出、每次行动改变什么、恐怖显现怎样与人物有关、结尾留下怎样的日常余波。地点和道具相同也可以有完全不同的故事；地点不同也可能共享同一个调查反转骨架。

CSV 可提供部件，人物经历负责把部件连接起来。候选最少能说清三句因果桥；只提供“雨夜＋旧楼＋失踪邻居”不算方向。库外原创同样可选，不把覆盖标签当成质量分数。

当用户提出新素材，先问它会怎样改变当前人物选择或读后感，而不是立即把所有新点子叠上去。保留正常生活、非伏笔细节与节奏松紧。

## 讨论与质疑

每轮优先处理一个高影响分歧，先复述用户当前选择，再呈现具体代价。用户偏好“更冷、更日常”可以直接成为设计约束，不需要证明它优于别人的口味。

质疑必须有对象和撤回条件，例如：“主人公已经没有继续留在这里的理由；如果此前的承诺使离开意味着具体损失，这项质疑可以撤回。”不要只说“不够恐怖”。有效答复出现后撤回攻击，不无限抬高标准。

如果安排红蓝队：蓝队提出最强可行方案；红队攻击因果、雷同、违约或过度解释；蓝队回应并修改；红队对实际修改复核，记录 supported/narrowed/defeated/unresolved。至少保存一个真实来回与改动证据。代理间结论只是评审意见，不能变成用户决定；未使用独立代理时明确是同一模型内部审查。

已确认项不反复提问。连续讨论没有改变人物、推进或结尾时，整理简报并根据既有授权进入下一阶段；不要为了固定轮数延长。

## 创作简报

共创工具使用七个字段，每项可简洁，也可包含多个人物；不要求建立长篇章节状态机：

| 字段 | 内容 |
|---|---|
| premise | 核心处境、目标恐惧与现实接口 |
| character | 经历、信念、利益、价值排序与不能轻易退出的理由 |
| causalChain | 人物选择如何改变处境；不固定调查或翻案顺序 |
| horror | 可感知的显现、客观残余、局部可观察关系及开放本体 |
| ending | 人物/关系/前文留下什么余波，怎样在日常重新启动 |
| constraints | 明确禁用、必须保留、可自主选择、有意未知 |
| form | 篇幅、视角、语言、叙事形式、正常段落等约束 |

共同构思阶段的门槛是足以执行，不是作者知道全部宇宙答案。当前版本需要通过四项审查：人物因果、去掉表面名词后的结构差异、用户约束、具体异常与开放终极本体。每项保留一句证据；不能只打四个勾。

## 收口与授权

- `ready_to_write`：七项可执行，阻塞项清空，当前简报审查通过；这只是准备状态。
- 结束讨论：用户确实收口，或已有授权足以让代理处理剩余内容并完成讨论。已由用户确认的字段无需再委托；尚由代理决定的字段仍须有有效委托。记录实际来源，不伪造“用户确认”。
- 按版本成文授权：只对明确版本有效，内容修改后重新核对新指令。
- “讨论结束后直接写”：可预先记录，讨论结束且当前版本就绪时生效，不反复问同一个许可；用户后来“只讨论/先别写”立即撤回。
- 用户改变主意“直接写，剩下你定”：复用已有决定，在新授权范围内补足余项并交接，不重新强迫多轮。

简报变更保留 supersedes 与理由，旧审查和收口失效；先复查当前版本。正文写作消费冻结简报，不自作主张推翻已定人物、禁用和结尾。

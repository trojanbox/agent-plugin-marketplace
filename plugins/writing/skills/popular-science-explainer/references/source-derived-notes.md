# Source-derived Method Notes

## Source basis

本 Skill 的首版方法抽象自用户提供的一支中文 Wi-Fi 科普视频。原视频没有独立字幕轨，但画面存在烧录中文字幕；分析时通过字幕区域 OCR 获得时间序列文本。

OCR 存在技术词和个别汉字误识别，因此它只用于观察**结构、节奏和叙事顺序**，不作为精确逐字稿或技术事实来源。本 Runtime 不打包原视频字幕，也不复制原作者的长段表达。

## 从样本中稳定观察到的模式

1. **从日常动作开始。** 先用人人熟悉的使用场景建立进入点，再暴露背后的隐藏复杂度。
2. **先给最小可理解模型。** 用低门槛的物理/直觉模型解释第一层机制。
3. **通过模型失败推动下一章。** 低效率、距离、反射、频谱有限等现实约束，成为引入下一项技术的原因。
4. **术语晚于直觉。** 常先展示“怎么做、为什么有效”，再给 ASK/FSK/PSK/QAM/FDM/OFDM/MIMO 等名字。
5. **量化技术收益。** 用 bit 数、并行路数、信道宽度等简单数字让提升可感知。
6. **类比具有连续性。** 同一段中重复使用道路/车道等心智模型解释相关技术，减少认知切换。
7. **旁白步幅小。** 烧录字幕大多对应短时间片，一个片段只推进一个局部逻辑动作；深度来自连续累积。
8. **视觉承担空间信息。** 图形、波形、星座图等负责展示关系，旁白主要解释因果和意义。
9. **结尾先技术压缩，再回到生活。** 情绪表达集中在已经完成技术解释之后，避免前置空泛升华。

## 本地化原则

- 学方法，不模仿身份；
- 不固定使用样本中的具体比喻；
- 不把工程类的“问题 → 解法”硬套到所有自然科学主题；
- 对自然科学、数学、发现史分别使用适合的模型递进方式；
- 正确性和证据优先于叙事顺滑。

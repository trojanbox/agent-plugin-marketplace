# 【创作·结论】Issue 交付

标题：

```text
【创作·结论】【书名】<本轮主题>
```

同一轮讨论只维护一份对应结论；已有同轮结论时更新，不重复创建。

## 建议正文

按实际适用项组织，不为模板完整制造空内容：

1. 结论信息与来源；
2. 背景与目标；
3. Current Creative State；
4. Scope / 非目标；
5. 最终创作结论；
6. 关键 Owner 合同；
7. 重要 D-xxx；
8. 被否决 / superseded；
9. Preserve Set；
10. deferred / creative_open；
11. Storybook 调整范围 / Owner Mapping；
12. 受影响章节 / Manuscript；
13. 验收要求；
14. 追溯关系。

## 跨结论覆盖

新结论只覆盖自己明确 supersede 的子范围；说明对应 Owner / 关系 / 章节。除非完全替代，不宣布旧结论整体失效。

## 完成条件

- 来源读取完整；
- Coverage 无关键遗漏；
- Standalone Reader Gate 通过；
- creative_open / deferred / 非目标未丢失；
- 无未解决 conflict；
- GitHub Issue 真实创建/更新并回读；
- 双向审计通过。

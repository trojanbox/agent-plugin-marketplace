# 恐怖方向库：研究依据、数据合同与边界

检索与核验日期：2026-09-16。用于维护库、追溯来源或审查同质化风险时按需读取；普通构思只读取选择器返回的少量条目。机器可读来源见 [sources.json](../catalogs/sources.json)。

## 1. 哪些是外部依据，哪些是原创设计

| ID | 外部依据与已读取材料 | 对本实现的启发 | 不能由它推出什么 |
|---|---|---|---|
| R1 | Doshi 与 Hauser 的 [短篇故事实验作者预印本摘要](https://arxiv.org/abs/2312.00506)；对应[期刊 DOI](https://doi.org/10.1126/sciadv.adn5290)入口本轮返回 403 | AI 构思帮助与群体作品相似性同时出现的结果，使跨候选、跨作品结构比较成为必要关注点 | 不能据此断言所有模型、职业作者、长篇或多轮共创都会趋同；不能证明本库已改善文学质量 |
| R2 | Lehne 与 Koelsch 的 [张力与悬念理论模型](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2015.00079/full) | 除了谜底是否未知，冲突、期待、时机及情感相关后果也能支持张力；拆开推进方式、时间与代价 | 不是最优恐怖公式或固定场次比例，也没有验证本库条目 |
| R3 | OpenLearn 的 [Start writing fiction](https://www.open.edu/openlearn/mod/oucontent/view.php?id=1622&printable=1) 创作教学 | 从人物生活、欲望、矛盾与场所形成行动，候选先补人物为何行动的因果桥 | 教学建议不等于读者效果实验；不要求照搬课程所提作品或作家 |
| R4 | OpenLearn 的 [Approaching prose fiction 术语教学](https://www.open.edu/openlearn/history-the-arts/literature/approaching-prose-fiction/content-section--glossary) | 区分说话者与感知者、事件先后与叙述安排；独立设计视角与信息接触范围 | 不证明非线性、多视角或不可靠叙述必然更好 |
| R5 | Andersen 等的 [娱乐性恐惧实地研究摘要](https://www.psychologicalscience.org/journals/psychological-science/0956797620972116/)；鬼屋现场样本 110 人 | 恐惧更强并不保证更享受，保留缓和、强度偏好与真实日常满足 | 场景不是小说，不能换算最优血腥量、节奏比例或统一恐惧阈值 |

**全部 CSV 行及开发期样例均为本项目原创推演，`provenance=original_synthesis`。** `source_ids` 只指向启发设计的原则；不表示论文作者提出、推荐或验证该行的场景、行为或异常。R1 支持整个流程的重复风险关注，不充当任何具体异常的学术背书。这里没有复制论文大段文本、真实民俗秘仪、具体作品情节或作者风格。

使用真实行业、医疗细节、历史、地方习俗或宗教实践时，仍需为该故事另行核对相关事实；库中概念不能充当领域资料。虚构习俗要保持虚构身份，不把真实群体的陌生性当成恐怖证据。

## 2. 覆盖地图与加载方式

初始库为 14 个维度、每维 18 条，共 252 条。数量表示可探索部件数量，**不是剧情数量、完整性证明或文学质量评分**。各维都可跳过，也允许原创库外方向。

| 文件/维度 | 主要问题 | 初始覆盖 |
|---|---|---|
| `contexts.csv` | 什么生活空间使行动互相影响？ | 家庭、劳动交接、公共设施、交通、生态、在线服务、共同仪式等场景功能 |
| `pressures.csv` | 人物为什么现在必须作选择？ | 生计、承诺、时间窗口、照护、声誉、利益与自主权 |
| `relationships.csv` | 谁依赖谁，谁能同意或拒绝？ | 亲近关系、服务关系、权力差、共同秘密、继任与群体代表 |
| `fears.csv` | 哪种原本可信的生活条件遭到破坏？ | 自主、信任、责任、边界、知识、公共后果、非人尺度 |
| `engines.csv` | 什么行为不断产生下一个处境？ | 维护、协作、协商、分配、获益、竞争、掩饰、依恋、离开、见证及有限调查 |
| `anomalies.csv` | 哪种具体关系不再成立？ | 空间、时间、感官、物质、身体、生态、权限与语言行为 |
| `evidence.csv` | 人物凭什么判断并行动？ | 物理后果、协作、有限测量、受益分配、他人行动与环境响应 |
| `perspectives.csv` | 谁在讲，谁能感知哪些事实？ | 单焦点、双视角、有限集体、旁观者、继任者、异议者 |
| `temporal_forms.csv` | 事件如何在时间中被组织？ | 连续值守、回访、余波、等待、不同步、跨代、局部完成 |
| `rhythms.csv` | 压力何时及怎样改变？ | 关系先行、显现后果、迁就、修复、责任重分配、日常满足 |
| `choices.csv` | 人物具体做什么，拒绝什么？ | 照护、自保、偏爱、竞争、隐瞒、继续获益、边界、退出与责任 |
| `costs.csv` | 行动获得什么，又留下什么损失？ | 关系、时间、劳动、身体、声誉、空间、知识与共同负担 |
| `endings.csv` | 哪项人物行动完成，什么继续作用？ | 关系边界、任务完成、离开、共存、责任与伦理余量等结尾作用 |
| `everyday_anchors.csv` | 哪种普通生活经验能带出回响？ | 请求、交接、共同动作、休息、便利、修理、称呼与劳动 |

`engines + choices + costs + endings` 是结构比较的重点；不能让场景、视角或道具的不同掩盖这四项相同。默认少量维度先选择，缺哪项再添加；不要把 14 行勾成每篇必备的写作清单，也不要把整库读进每次对话。

本库覆盖较广但不穷尽恐怖文学。当前仍偏向现实生活中的关系与行动；长篇人物网络、地方史、具体职业、语言风格等应围绕当前作品另行深入。增加条目应解决可命名的覆盖缺口，避免为凑数复制近义项。

## 3. CSV 合同

统一 UTF-8 CSV、首行固定 12 列，按 CSV 引号规则处理逗号、换行与双引号，不应直接以逗号拆分一般输入：

```text
id,dimension,label,family,tags,content_tags,prompt,use_when,avoid_when,risk,source_ids,provenance
```

| 列 | 合同 |
|---|---|
| `id` | 稳定、全库唯一，形如 `engines-001`；更新措辞不改 ID，不以删行重排编号 |
| `dimension` | 与 CSV 文件名相同的稳定小写标识 |
| `label` | 简短中文名称，概括一个部件而非整篇情节 |
| `family` | 小写英文与短横线；同维中按因果机理分组，供保守重复提醒使用；不同维同名不表示同一机制 |
| `tags` | 非空、以 `|` 分隔的小写标识；用于定位主题与探索偏好，不是剧情兼容性结论 |
| `content_tags` | 以 `|` 分隔的已标记内容类别；无相关内容时空；用于机械排除，不能代替语义边界审查 |
| `prompt` | 原创可组合部件，只描述局部机制、关系或方法；不提供固定开头到结尾路线 |
| `use_when` | 人类/模型需核对的适用条件，不是脚本已验证的事实 |
| `avoid_when` | 不适用情况，必须在候选因果桥审查时判断 |
| `risk` | 容易造成的套路、失真或表达伤害；不是把风险内容强制写入故事 |
| `source_ids` | 非空、以 `|` 分隔，须在 `sources.json.sources[].id` 中存在 |
| `provenance` | 本版固定 `original_synthesis`，明确为原创推演 |

`family` 比较只是代理信号。两个不同 family 仍可能被写成同一路径，同一 family 也可能因人物与因果关系不同而成为成立的新作。脚本结果需保留审查标识，不能自动盖章“原创”“兼容”“不重复”或“最优”。

内容词表：

| 标签 | 排除所涉及的内容 |
|---|---|
| `minors` | 未成年人作为涉及对象 |
| `death` | 死亡、亡者或以死亡为核心的失去 |
| `blood` | 明确出血、血液或血腥描写 |
| `body_horror` | 身体结构、功能或边界的恐怖性改变；普通触摸或疲劳不自动标记 |
| `animal_harm` | 动物受伤、死亡或虐待 |
| `sexual_violence` | 性暴力；仅保留排除接口，本库不主动提供此类候选 |
| `self_harm` | 自伤；仅保留排除接口，本库不主动提供此类候选 |
| `abuse` | 虐待；不把普通意见分歧自动归入 |
| `medical` | 医疗情境、身体损伤处理或需健康照护的情境 |
| `religion` | 宗教或具有宗教性质的虚构公共仪式 |
| `discrimination` | 以歧视为具体事件内容；普通权力差不自动归入 |

词表含尚无正向候选的保留项；选择器如只接受当前库已出现标签，未出现标签应报告未知/无候选，**不能把它误当已自动验证的安全承诺**。讨论记录中的完整用户禁区始终优先，包含未被脚本识别的自由文字边界。标签针对 `label/prompt/use_when` 中实际建议的内容；`avoid_when/risk` 中指出不应采用的反例不等于候选建议出现该内容。空 `content_tags` 只表示当前标注未发现相关类别，不表示生成文本永远不会涉及它。

维护者新增或修改行时，复核语义内容与标签一致；不能仅凭敏感词搜索填标签。选择后、写作前及完稿时再次对照用户禁区。脚本排除对已标注数据生效，既不是临床诊断，也不是内容分级保证。

## 4. 开发期样本与证据边界

仓库内的开发期材料位于 `tests/evidence/horror-catalog-samples.md`：固定同一成年家庭照护场景，实际试写四个片段，比较维持照护、资源分配、拒绝继承与继续获益的行动因果链。它们由创作代理生成、经代理人工式结构比较，不是人类读者盲测或随机对照。

该文件属于仓库维护证据，不是安装后的 Skill 运行依赖，日常构思无需读取。样本只能说明本次设计容许不同结构；不能证明 252 条部件覆盖穷尽、实际作品不再同质化或读者恐惧效果提高。相关效果仍需多篇完整作品及读者或编辑反馈验证。

## 5. 红蓝队反馈的维护结论

- 对“道具增多但结构相同”的攻击：方向先写人物需求 → 主动选择 → 处境改变 → 结尾作用；结构比较优先四个核心维度。至少保留不以调查推进、不以物件尾针收束的候选，必要时直接原创库外方向。
- 对“研究为原创条目背书”的攻击：保留来源类型、读取范围、适用限制和 `original_synthesis`；不使用未经验证的效果分数。
- 对“全是正向伦理行动”的攻击：补入自利、偏爱、羞耻、竞争、依恋与推迟面对后果的路径；人物的可信度不以道德正确为前提，也不以超自然惩罚代替关系因果。
- 对“抽样距离代表文学质量”的攻击：算法只能提供可追溯的候选和结构提示，人物可信度、语义兼容、文本质量与用户口味仍需逐项判断。
- 对“讨论和审查无限延长”的攻击：已经确认的决定保留；每轮解决会改变作品的关键未决项；不为了角色扮演而增加争论。用户明示直接创作或授权代定时，按实际授权范围收束。

本文件记录设计依据与证据边界；实现测试、实际红蓝队攻击与处置状态应由实施记录另外保存，不能把这里的设计说明当作已通过测试的证明。

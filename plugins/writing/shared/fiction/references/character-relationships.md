# 人物深度与关系轨迹

需要把已有骨架人格深化为可观察的人，或重要关系仍停留在“逐渐变化”的空话时读取。

## Character Depth Map

以下是可探索方向，不是必填字段：

### 当前驱动力
他现在真正想保护、得到、避免或完成什么？为什么现在重要？区分长期价值、当前目标和短期现实需要。

### 行为惯性
压力、未知、羞耻、损失、关系冲突来临时，他通常怎么处理？不要复制固定人格模板。

### 内部张力
寻找同时为真的两面，而不是硬塞“优点/缺点”：例如真心爱孩子，同时需要控制孩子；非常可靠，同时无法接受别人帮助。

### 默认社交基线
低压力、没有现实冲突时，这个人通常怎样对待第一次接触的人？他默认有多客气、多直接、多戒备、多热情？面对服务人员、陌生同事、陌生智能体或权力更高 / 更低的人是否有稳定差异？

默认社交基线用来定义“人物没有被特殊压力推离时通常从哪里出发”。后续迁怒、尖锐、失控可以偏离基线，但需要现实压力、关系积累或利益冲突支撑。

### 关系中的不同面貌
同一个人面对父母、伴侣、孩子、同事可以有不同表现，但这些差异仍应来自同一套人格逻辑。

### 真正影响现在的过去
只保留能够解释今天行为、判断或关系的过去。不要为了完整档案制造童年创伤、秘密和无用履历。

### 故事留下什么
人物可以成长、恶化、局部改变、坚持原价值、被考验但不变、现实位置变化而人格变化很小，或自己不变却改变别人。不强制正向 Character Arc。

## 可观察性

人物设定必须最终能落到行为与关系中。不要只写“他自尊心强”，要找到读者能亲眼看见的表现方式，但不在本阶段写正式 prose。

可用检查：

- **遮名测试**：去掉名字后，关键反应是否还能区分人物。
- **同刺激差异测试**：同一事件发生时，不同人物是否因价值、关系和处境自然产生不同反应。
- **场景一致性测试**：关键场景里的行为是否真的来自人物，而不是剧情临时要求。
- **坏消息反应测试**：重大刺激到来时，人物是否先出现符合人格与现实利益的情绪、判断、自保或抱怨，再进入行动；若所有人都迅速理性解决，优先判为失真。
- **公开/私下温差测试**：同一个人在正式会议、同级私聊、亲密关系和独处时，表达是否允许因权力与关系不同而变化。
- **阶段泄漏测试**：当前场景是否使用了关系后期才自然成立的称呼、互损、揭短、触碰、替答或私人追问。

## 互动边界 / Interaction Boundary

重要关系除了“亲近 / 疏远”，还要按需确认当前阶段哪些互动已经自然成立：

- 称呼从正式到随意的程度；
- 普通玩笑、私人玩笑、互损和揭短；
- 直接打断、反驳、命令或替对方回答；
- 询问家庭、感情、身体、过去等私人问题；
- 身体接触、靠近、进入私人空间；
- 替对方做决定或介入对方选择；
- 在对方面前暴露脆弱、发脾气、请求安慰或承认害怕。

这些边界不要求做成固定表格，也不等于法律 / 系统权限。它们描述“以这两个人目前的共享经历和安全感，这样互动会不会显得自然”。

稳定默认基线由 Characters 保存；跨章关系阶段由 Story 保存；近期 Planning 存在时可以摘录当前章需要提醒的边界，但正文也可以直接从 Characters + Story + 已有 Manuscript 恢复当前态。不要因为作者知道两个人以后会成为恋人、挚友或损友，就把终点关系的互动尺度提前写进初见。

## 关系轨迹

重要关系按需看：

- 起点实际是什么状态；
- 双方如何理解这段关系；
- 权力、责任、依赖和边界；
- 只有这两个人才有的共享历史；
- 哪些事件真实改变或考验关系；
- 读者需要亲眼经历哪些 marker scenes；
- 终点进入什么新状态。

关系可以变化，也可以始终稳定。不要为了“有弧线”强迫每段关系先破裂再修复。

## 不同人物的深化成本

- 核心人物：按需深入多个维度。
- 重要配角：至少有自己的诉求、关系位置、行动理由和独立于主角的生活逻辑。
- 功能小角色：不主动设计完整人生；只有故事证明需要时才升级。

# 节奏审查

## 唯一问题

**连续读下去为什么会不会累，为什么还想不想继续读？**

先读取 `review-contract.md`。本审查模式 以连续阅读为前提，优先连续多章、Story Movement 或全书，不把单章“快/慢”当主要判断。

## 检查

- 场景发动机制长期重复；
- `查 → 核 → 等 → 看结果 → 再查`、会议、问答、同一种恐怖刺激等固定骨架；
- 小说退化成案例集 / 教程；
- 连续多章只有信息，没有值得亲自经历的瞬间；
- 情绪曲线长期同温；
- Reader Pull、局部高潮和阅读锚点；
- 重大离别 / 真相 / 死亡前的情感投资是否足够；
- 生活场景是否承担人物、关系、现实压力和存在感；
- 中段疲劳、后段赶进度、扩写只拆章不增加经历。

详细连续通读方法读取 `revision-methods.md` 与 `scenes-information-world.md`。

## Reader Pull 的证据路径

连续阅读时，在关键场景或章节交界记录三个问题：

1. **期待**：此时读者主要在乎哪个人、结果或未解决的处境？
2. **经历**：这段有没有值得亲自读的选择、行动、相处、失败或等待？如果压成一句剧情梗概，会损失什么？
3. **变化**：前面的期待得到回应、转向或积累了吗？重复流程是否只交付了信息，却没有新的关系与命运代价？

引用实际章节证据说明“为什么想继续读 / 为什么疲劳”，同时标出读者仍愿意经历的场景，作为修订 Protect Set。普通生活、慢场与暂时无解可以有持续的阅读吸引力；**不为提高 Reader Pull 强制添加钩子、反转、反派或快节奏**。单句难懂交给可读性审查，人物动机根因交给人物 / Story Owner。

## 边界

节奏问题如果来自高影响 Story / Character 设计缺陷，回【创作·讨论】；不在审查阶段自行新增支线、反派或世界设定。

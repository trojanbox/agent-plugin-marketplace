# Publication Proofread / 出版终校模式

仅在用户明确要求“出版终校 / 最终校对 / 发布前最后一遍 / 来一轮终校”，或 `fiction-final-review` 已完成内容级连续阅读、现在进入成书层检查时读取。

## 1. 终校顺序

终校不是再做一次创作重写。按项宏处理：

1. 先确认当前 Manuscript 版本身份与终审范围；
2. 从头到尾连续阅读，先找内容级 P0/P1；
3. P0/P1 清空后，再处理句子级明确问题与文本卫生；
4. 修改后只重读受影响章、相邻章和相关弧线；高影响改动才触发全书重新连续阅读；
5. 最后记录版本绑定的 `Publication Readiness Reviewed`。

## 2. 成书层检查

重点检查：

- 错字、漏字、重复字、病句；
- 中文标点、引号、括号、冒号、破折号的一致性；
- 中文标点前后的异常半角空格、尾随空白；
- 章节标题格式、编号连续性、重复标题；
- 人名、机构名、型号、关键术语首次与后续写法；
- 固定结尾、题记或必须保持原样的文本是否被误改；
- 多轮合段 / 拆段以后遗留的格式污染；
- Markdown 转出版文本时可能暴露的星号、空行或标题层级问题。

统计和脚本只负责**确定性文本卫生**，不能自动决定“这句话文学上不好”。

## 3. 确定性检查器

Runtime 提供：

```bash
python plugins/writing/shared/fiction/scripts/manuscript-hygiene-check.py <manuscript-dir-or-files>
```

如果终章有固定最后两行，可额外传：

```bash
--expect-penultimate-line "空白输入框。" \
--expect-final-line "闪烁光标。"
```

脚本检查：

- 中文标点前异常空格；
- 中文标点 / 闭合引号后夹在连续正文中的半角空格；
- 行尾空白；
- 中文双引号数量不配对；
- 纯数字章节文件（如 `001.md`）的单一 H1 标题；
- 同目录数字章节编号是否连续；
- 可选固定结尾。

脚本报错只证明文本卫生异常；修复前仍应看具体上下文，避免机械删除有意空格。

## 4. 允许修改与停止边界

明确的标点、空格、错字、格式污染可以直接清理；句子、对白、段落如果涉及人物声音、信息释放、节奏或语义变化，先按 Review Contract 诊断。

当 P0/P1 已清空，剩余项只能解释为“另一种写法也成立”，标记 `Protect / No Change`。出版终校的价值包括**确认哪些地方不要再改**。

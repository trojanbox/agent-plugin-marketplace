# Fiction Genre Knowledge Index

类型知识是三个通用小说 Skill 的按需辅助资料，不是独立主流程。只加载当前作品已经确认或正在认真评估的类型文件；不存在的类型 reference 不要猜路径。

当前可用：

| Genre knowledge | 文件 | 使用条件 |
|---|---|---|
| 心理恐怖 / Psychological Horror | `psychological-horror.md` | 作品以恐惧、惊惧、持续不安、存在威胁或现实/自我/关系不安全感作为重要阅读体验，并希望恐怖主要作用于心理、认知、情感、关系、身份或现实感 |

未来新增爱情、科幻、悬疑、历史等类型时，优先扩充本目录；只有某个类型形成独立、重复且可与主流程清楚互斥的用户任务目标时，才考虑升级为 Public/Internal Skill。

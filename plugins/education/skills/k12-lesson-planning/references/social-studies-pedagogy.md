# Social studies lesson-planning pedagogy

Read this file when the new lesson's primary subject is history, civics, geography, or economics.

## Standards and inquiry

Social-studies content standards are jurisdiction-specific. If standards alignment is requested, use the teacher's state/framework or obtain it. C3 is an inquiry-design framework, not a substitute content standard.

Use the C3-style inquiry arc to shape learning:

1. compelling/supporting questions;
2. disciplinary concepts/tools;
3. evaluating sources and evidence;
4. communicating evidence-based conclusions.

## Compelling question

It should be genuinely contestable, meaningful, age-appropriate, and answerable with evidence. Avoid factual yes/no questions masquerading as inquiry.

## Source set

Prefer 2 complementary sources for a single lesson, with real provenance:

- title / creator / date / collection/archive;
- verified URL/catalog info only when actually verified;
- explain why the pair creates useful tension or contrast.

Public-domain/government text can be excerpted within its terms. Images/cartoons/copyrighted texts should usually be cited and supplied by the teacher rather than reproduced.

Never invent quotations, page numbers, archives, URLs, or document provenance.

## Lesson arc

A practical single-lesson sequence:

`Background knowledge → Source work → Discussion → Evidence-based Exit`

Source analysis questions can progress:

`Observe → Source/Contextualize → Corroborate/Connect → Claim`

## Grade bands

- **K–2:** photographs/artifacts/oral histories; oral discussion + drawing/simple sentences.
- **3–5:** short scaffolded primary sources, written analysis, paragraph claim/evidence/reasoning.
- **6–8:** more complex sources, independent sourcing, 1–2 paragraph evidence-based conclusions.
- **9–12:** challenging primary/secondary sources, contextualization/corroboration, counterevidence and historical complexity.

## Disciplinary guardrails

- avoid presentism without historical context;
- avoid flattening multi-causal events into one easy cause;
- distinguish source claim, evidence, interpretation, and later hindsight;
- make missing perspectives visible when they matter.

## Exit Ticket

Answer the supporting question with evidence from the sources, sized to the time available. Give criteria that specify what counts as a defensible claim/evidence link.

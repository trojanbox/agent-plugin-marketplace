# Math lesson-planning pedagogy

Read this file when the new lesson's primary subject is mathematics.

## Inputs and defaults

Infer what the conversation already establishes. Priority if missing: grade → topic/standard → curriculum/state when it materially changes the design. Default to a realistic 45–60 minute period and universal access.

Only use curriculum-specific terminology (for example IM routines/MLRs) when the teacher explicitly names that curriculum or the supplied lesson/material establishes it.

## Lesson arc

A broadly useful problem-based arc is:

`Launch → Explore → Discuss → Synthesize → Exit Ticket`

- **Launch:** activate just enough prior knowledge; do not model away the target thinking.
- **Explore:** students attempt worthwhile mathematics before the teacher formalizes a method.
- **Discuss:** allocate real time (often 10+ minutes) to compare strategies, representations, errors, and generalizations.
- **Synthesize:** name the mathematical relationship/notation after the thinking is visible.
- **Exit Ticket:** use a fresh case that exposes the key misconception.

## Grade bands

- **K–2:** concrete story situations and drawings/manipulatives. For addition/subtraction, vary situation structure (add-to, take-from, part-whole, compare) and unknown position. Never teach keyword shortcuts.
- **3–5:** problem-based + gradual formalization. Arrays/area models, fractions on number lines, place-value/area reasoning as appropriate.
- **6–8:** ratios, tables, double number lines, coordinate graphs, equations, proportional vs non-proportional cases.
- **9–12:** mathematical modeling, functions/structure, multiple representations; formal notation follows conceptual work when possible.

## Structural coverage

Before writing the problem set, enumerate the structural cases the standard actually requires. Include both baseline and hard/misconception-prone cases in required student work.

A case mentioned only in teacher notes does not count. A hard case placed only in a bonus does not count.

Examples of discriminating cases:

- start-unknown/change-unknown in story problems;
- fraction/decimal cases when the standard includes rational numbers;
- product smaller than factors when multiplying decimals/fractions;
- just-below/at-boundary values for rounding;
- linear-but-not-proportional examples when distinguishing proportional relationships.

## Representations

Choose a representation that matches the concept:

| Concept | Useful representation |
|---|---|
| additive / part-whole | tape diagram, part-whole model |
| multiplication / area | array, area model |
| fraction quantity | number line |
| ratio / rate | ratio table, double number line |
| proportional / linear | table, coordinate graph |
| equation reasoning | balance / variable representation |
| geometry | labeled diagram |

The representation should help students think; a worked table that gives away the answer stays teacher-facing.

## Look-fors and misconceptions

For major tasks, name at least 2–3 concrete look-fors:

- what student response/representation might appear;
- why it matters mathematically;
- what teacher move follows.

Misconceptions use: **What students do → Why it happens → Teacher move**.

## Exit Ticket Gate

Use a fresh item that tests the hardest important structural case. Apply a misconception test: a student holding the lesson's main misconception should get this item wrong.

Work the answer yourself before presenting it. Define lesson-specific sorting criteria such as Got it / Almost there / Needs re-teaching; labels alone are insufficient.

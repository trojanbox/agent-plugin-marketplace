# ELA lesson-planning pedagogy

Read this file when the new lesson's primary subject is English Language Arts.

## Inputs

Determine grade band, strand (foundational reading / reading comprehension / writing / combined), target standard, and anchor text if any. Use a teacher-supplied text when present.

If selecting a text yourself, mark it as suggested. For copyrighted texts, cite title/author/source and have the teacher supply lawful copies; do not reproduce a protected passage merely because it is convenient.

## K–2

### Phonics / decoding

- explicit phoneme ↔ grapheme instruction;
- decoding and spelling connected;
- word lists only use taught patterns plus known graphemes;
- decodable practice for the taught pattern;
- no three-cueing / picture guessing / “first letter + context” guessing;
- word-reading exit ticket should include the target pattern and a contrast item.

### Read-aloud comprehension

Use a content-rich read-aloud beyond students' independent decoding level. Sequence text-dependent questions from understanding → detail → vocabulary → inference. Discussion is oral and every student needs a response opportunity.

## Grades 3–5

Typical arc:

`Launch → Close Reading → Think-Write-Pair-Share → Vocabulary → Evidence-based Writing → Exit`

- keep grade-level text complexity;
- scaffold through re-reading, vocabulary, annotation, discussion;
- do not replace the text with an easier summary;
- writing prompt points students back to exact evidence.

## Grades 6–8

Move from comprehension to literary/rhetorical analysis:

- assigned analytical lens for annotation;
- claim + evidence + reasoning;
- compare annotations/interpretations;
- analyze craft effect, not merely identify a device;
- introduce counterclaim/alternative interpretation by later middle grades when appropriate.

## Grades 9–12

Require analysis of *how* and *why* for a particular audience/purpose/context. Use sustained evidence-based argument or rhetorical analysis. Preserve complexity and let students wrestle with difficult passages; do not pre-explain the answer.

## Vocabulary and discussion

Teach a small number of useful Tier 2 / discipline words in the context where students need them. In discussion, prefer student-to-student reasoning; teachers probe and sequence responses rather than dominate.

## Look-fors

For reading/writing phases, identify what a strong response actually contains: cited detail, inference, craft explanation, reasoning link, counterevidence, etc. “Students are engaged” is not an instructional look-for.

## Exit Ticket

Target the hardest inference/application the lesson claims to teach. For grades 3–12, the prompt should require evidence. Keep it sized to the remaining minutes rather than assigning a take-home essay as an “exit ticket.”

# Science differentiation pedagogy

Use with the shared R1–R8 rules in `../../../shared/core/pedagogy.md`.

## Preserve three dimensions

Every tier retains the same phenomenon and the foregrounded SEP, CCC, and DCI. Below-tier students still investigate and construct explanations.

## Observation → Representation → Explanation

Use this progression to choose entry points:

- **Below:** structured observation → guided representation → scaffolded explanation/CER;
- **At:** representation → explanation/CER;
- **Above:** explanation → extension/generalization/competing explanation.

A useful Below prompt surfaces cognitive conflict: “I thought ___, but I observed ___. Now I think ___.”

## Acceptable supports

- structured observation prompts;
- guided data table with units/headers, but no interpretation prefilled;
- partial model students must complete;
- vocabulary box;
- CER sentence supports;
- prior-concept activation.

Do not pre-tell the scientific explanation or route Below students to a reading while peers do the investigation.

## Same phenomenon, same investigation

Materials/procedure/data should stay the same by default. Tier blocks describe only supports and extensions, which keeps the science experience coherent.

## Above-tier extension

Add engineering design, counter-phenomenon/anomalous case, quantification, competing-model evaluation, evidence-based rebuttal, or a substantive societal implication.

## Formative regrouping

Use actual observation/model/CER evidence to decide whether the barrier is observation → representation or representation → explanation. Regroup accordingly.

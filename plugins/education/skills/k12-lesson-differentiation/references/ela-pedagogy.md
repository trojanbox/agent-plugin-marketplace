# ELA differentiation pedagogy

Use with the shared R1–R8 rules in `../../../shared/core/pedagogy.md`.

## Same text, different access

All tiers normally work with the same grade-level text, essential question, and writing purpose. Change access/support, not the intellectual target.

Acceptable supports:

- chunked reading + annotation purpose;
- 3–5 vocabulary terms;
- sentence frames that structure thinking without supplying the claim;
- task-matched graphic organizer;
- read-aloud/partner/echo reading as teacher-side access support;
- fewer evidence examples if the standard/task type is preserved.

Do not replace the Below tier's argument with a summary, or swap in a simplified passage merely to make completion easier.

## K–5 foundational literacy check

Before treating “comprehension difficulty” as a comprehension problem, consider decoding/fluency. A student who cannot decode fluently may need separate foundational intervention; read-aloud access can bridge the lesson but does not remediate decoding.

## Task-matched scaffold examples

| Task | Primary support |
|---|---|
| narrative comprehension | story map |
| informational reading | main idea + evidence organizer |
| argument | claim–reason–evidence frame |
| craft/structure | annotation guide + effect frame |
| compare/contrast | evidence matrix/T-chart |
| vocabulary | word map |

Keep embedded supports to 1–2 per task and fade them.

## Above-tier extension

Require a genuinely new operation: craft-effect analysis, alternate perspective, cross-text synthesis, counterargument, generative writing, or a real forward-standard demand.

## Flexible grouping

Group placement is based on evidence from this lesson or recent reading/writing data. Ask for ORF/running records/phonics screener/writing samples when those would materially improve scaffolds, but do not block a reasonable default plan when they are unavailable.

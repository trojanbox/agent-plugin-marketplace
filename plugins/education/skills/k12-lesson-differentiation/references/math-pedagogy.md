# Math differentiation pedagogy

Use with the shared R1–R8 rules in `../../../shared/core/pedagogy.md`.

## Preserve mathematical scope

All tiers solve the same core mathematical problem/structure. Keep the hardest case in play. Reducing the Below tier to “easy numbers + procedures” is a scope failure.

## Prerequisite bridge and CRA

Identify the nearest prerequisite concept from the teacher's framework when possible; otherwise name the concept plainly and label any proxy as a proxy.

- **Below:** Concrete → Representational, then apply to grade-level task;
- **At:** Representational → Abstract;
- **Above:** Abstract → Connection/generalization/forward concept.

## Scaffold selection

Choose one primary representation based on the concept: tape diagram, number line, ratio table, area model, coordinate graph, equation balance, etc.

Below-level supports may include manipulatives, visual organizer, sentence support, or a simpler rehearsal case **followed by transfer to the original task**. Avoid keyword tricks and answer-revealing worked templates.

Embedded scaffold cap: usually 1–2 per problem.

## Fade pattern

- Problem 1: up to 2 supports;
- Problem 2: up to 1;
- Problem 3+: independent;
- Exit: 0–1 only if necessary.

## Above-tier quality

Extensions must add new thinking: generalize, prove, construct a counterexample, connect inverse/equivalent structures, preview a real forward concept, or create a problem. “Do ten more” is not a meaningful extension.

## Formative regrouping

Mid-lesson evidence should decide grouping. Example: after a key representation task, scan whether students can set up the structure independently; regroup by observed need, not fixed “ability.”

If formative evidence shows the root gap is conceptual rather than procedural, change the scaffold type rather than adding more steps.

# 教师课程设计：语言、地区、教材与课程标准按需适配

只有用户给定中国或其他非美国教育体系、需要当地教材/课程标准对齐，或者美国州标准/教材适配有实质性不确定时读取。两套教师 Skill 都可按需引用此合同；不额外创建区域专用 Skill。

## 1. 课程来源 Gate

先提取已经给出的 **教学语言、国家/地区、学段年级、学科、主题、教材及版本、课程体系/标准来源**。缺省时不假设美国或中国；若只是通用教案不要求精确官方对齐，可以标记“标准未核验”的通用学习目标继续设计。

精确标准对齐必要时：
1. 教师明确提供当前适用的官方标准文本/代码或可验证材料 → 使用所给版本，注明来源和适用范围；
2. 当前宿主可访问可靠官方来源且实际核对成功 → 可以进行版本绑定的精确对齐；
3. 缺少资料/无法核实 → 标记 `standard_unverified`，不杜撰“义务教育课程标准第 X 条”、美国州编号或教材章节；只在不依赖伪造对齐的范围内继续，必要时询问老师真实课标/教材。

不以“教材名称看起来很熟悉”推断具体页码、编排或权威目标；不能把美国标准与中国标准视为天然可一一对应。

## 2. 旧学科参考的适用边界

保留已有 `math / ela / science / social-studies` 四类 **教学方法**作为可选择的参考，不能把它们的美国体系术语自动升级成当地的课程标准。

- 数学：问题情境、结构案例、图形表示、学生尝试和纠错可按真实任务采用；年级目标与内容深度由当地课标/教材决定。
- 语文/本地母语：可使用文本证据、阅读理解、写作指导等通用方法；**英语母语 ELA 的 phonics、grade-level English texts 不得直接作为中文识字/拼音标准**。
- 中国学校英语或其他外语：不等于美国英语母语 ELA；依实际听说读写/语言运用目标与用户材料采用相应教学活动，需精确标准时核验本地课标。
- 科学以及物理/化学/生物：可采用可观察现象、探究、模型修正等一般方法；SEP/DCI/CCC 属特定体系概念，不在非美国课程中冒充法定教学目标。
- 历史/地理/道德与法治等：可采用可靠史料、证据、背景与不同观点对照；C3 是特定教学框架，不能代替中国或其他国家真实内容标准。价值内容明确其教育体系背景，不编造出处。

对于不在四类既有参考中直接对应的学科，依真实目标采用通用教学原则、可信教材和已核验标准设计；不要通过强行归类改写课程内容或凭想象造新的教育标准。

## 3. 主任务与失败边界

- **从零设计课堂** → `education/k12-lesson-planning` 主导；新课要求分层支持也留在该主 Skill。
- **基于已有教案调整** → `education/k12-lesson-differentiation` 主导；源教案必须真实可读取，缺源教案不得换成新教案，也不得因本地化消除源教案规定的认知目标。
- 当标准未核验，只承诺“通用课程设计/依据用户提供材料的适配”，不声称“完全符合当前官方课标”。用户明确要精确本地合规对齐且标准不可查时，报告阻塞的标准证据。
- 保留已有 K–12 学科专项方法、版权/隐私约束及 realistic time budget；用户不要求国际化时不加载本 reference。

## 4. 核对目标

输出必须标记当前使用的是 `user_provided`、`official_verified` 或 `standard_unverified` 何种标准证据，并能追溯到用户提供材料/已核验的可信来源；没有真实核验时不得以“当前标准要求”作断言。

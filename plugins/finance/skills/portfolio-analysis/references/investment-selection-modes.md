# Investment Selection Modes / 投资标的选择模式

仅在用户明确要求“还应该买什么 / 帮我筛选标的 / 适合长期持有的有哪些 / 找短期可能快速重估的机会 / 两类标的应该怎么看”时读取。

本 reference 解决的是**一次性候选选择方法**，不把任何候选包装成保证收益。候选进入长期观察池后，持续扫描、状态变化与触发监控转 `finance/market-radar`。

## 0. 先定义 Selection Mode

先确认或推断用户要解决的是哪一类目标：

### Long-Horizon / 长期持有

目标是找到能够跨周期持有、通过盈利增长/现金流/合理再投资或稳定风险溢价持续创造回报的资产。

- 用户没有给时间范围时，默认把“长期”理解为多年而非几周几个月，并明确这是分析口径；
- 关注的是**可持续复利 + 可承受回撤 + 合理买入价格**；
- 不以“最近涨得最好”作为核心筛选信号。

### Tactical / Catalyst-Driven / 短期催化

用户说“短期爆发 / 短线机会 / 未来几周几个月可能快速上涨”时，统一按 **tactical / catalyst-driven** 模式处理。

- “爆发”是用户目标描述，不是收益承诺；
- 必须存在可观察的催化、预期差或供需/资金结构变化，不能只因为图形漂亮或热点很热；
- 默认适合股票、ETF、流动性较好的交易型资产；普通场外主动基金通常不适合作为短期交易工具，因为 NAV 滞后、持仓披露滞后、申赎和费用结构会削弱时点控制。

如果用户没有说明长期还是短期，而两种模式会导向完全不同的候选，先澄清；如果用户明确要同时看两类，可以分成两个候选池，禁止混用同一套评价标准。

---

## 1. 先看 Portfolio Role，再看产品名字

任何候选进入筛选前先回答：

1. 它在当前账户/组合里承担什么角色？
2. 它增加的是新的风险来源，还是重复已有暴露？
3. 用户的账户 mandate 是进攻、高增长、防守、低波、现金管理，还是其他？
4. 如果没有真实金额/权重，只做定性暴露判断，不伪造精确配置比例。

典型角色：

- Core growth / 核心增长；
- Defensive equity / 防守权益；
- Income / 收益；
- Inflation / commodity hedge；
- Duration / fixed-income stabilizer；
- Tactical theme / 战术主题；
- Idiosyncratic alpha / 主动选股或主动基金 alpha。

如果候选只复制已有 AI、半导体、美股大型科技、红利等同一 thesis，需要把“重复风险”明确写在结论里。

## 2. Long-Horizon：适合长期持有的核心筛选

长期候选至少检查以下维度。不同资产类型权重可以不同，但不能只看单一指标。

### 2.1 Durable Economic Engine / 可持续收益引擎

- 收入、利润、现金流的长期来源是否清楚；
- 需求是结构性增长、周期性增长还是一次性红利；
- 资产是否有足够长的再投资 runway；
- 长期回报是否依赖持续提高估值倍数。

### 2.2 Quality & Resilience / 质量与韧性

对公司：

- ROIC/ROE、FCF 转化、利润率质量；
- 净现金/杠杆、偿债能力；
- 周期底部是否仍能生存并继续投资；
- 会计质量、SBC、并购依赖与一次性调整。

对基金/ETF：

- 底层资产盈利质量和集中度；
- 历史大回撤及修复；
- 流动性与结构性风险。

### 2.3 Competitive / Structural Edge / 结构优势

- 护城河是否有数据支持；
- 行业结构是否允许长期赚取超额回报；
- 监管、技术、渠道或替代品是否在侵蚀优势；
- ETF 的指数规则是否真的能长期捕获目标因子，而非只包装一个短期热点。

### 2.4 Management / Manager Quality / 管理质量

公司：管理层资本配置、治理、并购、回购、分红和稀释纪律。

主动基金：

- 基金经理真实任职期；
- 是否跨越不同市场环境；
- 风格是否稳定；
- 规模增长是否破坏策略容量；
- 换手、回撤、离任/接任风险；
- 超额收益是否来自可重复过程，而非一次行业押注。

### 2.5 Valuation & Expected Return / 估值与预期回报

- 好资产不等于任何价格都值得长期买；
- 至少检查历史估值、同业/合理基准、盈利增长与估值是否匹配；
- 区分“高质量所以贵”和“贵到需要极端增长才能成立”；
- 需要完整 DCF/Comps 时转 `valuation-analysis`。

### 2.6 Portfolio Fit / 组合适配

- 与现有资产底层持仓、行业、地区、风格、币种的重合；
- 是否改善组合的独立风险来源；
- 是否符合该账号的 mandate；
- 防守账户不能因为某资产长期回报高就忽略回撤与相关性；进攻账户也不能把“高波动”误当“高预期回报”。

### 2.7 Long-Horizon Invalidation

至少给 1–3 个长期 thesis 失效条件，例如：

- 核心产品竞争力持续下降；
- ROIC/FCF 结构性恶化；
- 基金经理离任或风格发生实质漂移；
- 指数规则改变导致风险暴露变质；
- 估值隐含的增长要求显著超出可验证基本面。

### 2.8 长期候选的默认结论

使用：

- `Strong long-term candidate`：长期收益引擎、质量、估值和组合适配同时成立；
- `Watch / wait for price or evidence`：资产质量可以，但价格/证据/组合重合暂不支持新增；
- `Weak long-term fit`：长期引擎、治理、结构或组合适配存在核心缺陷。

不要只用近 1/3/12 个月涨幅给长期候选排序。

## 3. Tactical：适合短期快速重估的核心筛选

短期候选的核心不是“便宜”，而是 **催化 + 预期差 + 可交易性 + 明确失效条件**。

### 3.1 Catalyst / 催化必须具体

优先选择有日期或可观察触发器的事件：

- 财报 / guidance；
- 产品发布、价格调整、重大订单、产能释放；
- 监管/政策节点；
- 指数纳入/调仓；
- 资本回报、回购、分拆、并购；
- 供需拐点、库存拐点、价格拐点；
- 市场已经知道事件但低估其幅度或概率。

“AI 很火”“行业景气不错”“最近涨得快”不算充分催化。

### 3.2 Expectations Gap / 预期差

检查：

- consensus / 市场隐含预期是什么；
- 最近预期修正方向；
- 候选的上行需要哪些新事实超过预期；
- 好消息是否已经被价格充分反映。

短期机会最常见的来源是**事实变化速度 > 市场预期变化速度**，不是单纯“基本面很好”。

### 3.3 Market Confirmation / 市场确认

作为辅助证据检查：

- 相对强弱；
- 成交量/流动性变化；
- 趋势是否与催化方向一致；
- 是否存在明显拥挤、逼空或缺口风险。

技术/价格行为只能作为确认或风险信号，不能单独替代基本事实和催化。

### 3.4 Valuation & Asymmetry / 赔率

- 催化成功后的上行空间是否还有意义；
- 催化失败的下行是否可承受；
- 当前估值是否已经把完美结果计价；
- 对高波动品种重点看 gap risk，而非假设可以精确止损。

### 3.5 Liquidity & Instrument Fit / 工具适配

- 成交活跃度和退出难度；
- ETF 的折溢价、跟踪误差、QDII 额度/申赎限制（适用时）；
- 普通场外基金 NAV 与披露滞后是否让短期 thesis 无法有效执行；
- 杠杆/衍生品若未明确请求，不主动扩展。

### 3.6 Tactical Invalidation & Time Stop

每个短期候选必须同时给：

- `Catalyst window`：预期在什么时间段验证；
- `Invalidation`：什么事实出现就说明 thesis 错了；
- `Time stop`：如果催化窗口过去仍未发生，不能无限把短期 thesis 改写成长期持有理由。

禁止因为价格下跌后“舍不得卖”就把短期候选静默升级为长期资产。

### 3.7 短期候选的默认结论

使用：

- `Actionable tactical setup`：催化、预期差、赔率和可交易性同时较清晰；
- `Watchlist`：催化存在，但预期差/价格/时点未到；
- `No setup`：只有故事或热点，没有可验证触发器与赔率。

不使用“必涨 / 大概率翻倍 / 稳赚”等确定性表达。

## 4. 不同资产类型的关注点差异

| 资产类型 | 长期重点 | 短期重点 |
| --- | --- | --- |
| 股票 | 业务质量、ROIC/FCF、护城河、管理层、估值、再投资 runway | 财报/订单/产品/政策催化、预期差、估值与交易拥挤、流动性 |
| 主动基金 | 基金经理、长期过程、风格稳定、回撤、规模/容量、费用、组合重合 | 通常不优先做短线；只有明确风格/行业催化且工具结构允许时才考虑 |
| ETF | 指数规则、底层资产质量、费用、跟踪、流动性、组合角色 | 行业/宏观/政策催化、资金流、指数调仓、估值、流动性/折溢价 |
| 债券/固收 | 信用质量、久期、收益率、利率敏感度、费用、组合稳定作用 | 央行/利率/信用事件催化，久期和流动性；避免伪精确方向交易 |
| 黄金/商品 | 真实利率、供需、央行/结构需求、分散价值 | 宏观事件、美元/利率、供需冲击、仓位拥挤与波动 |

## 5. Candidate Selection Output Contract

用户要求“帮我选”时，默认输出：

1. `Mode & Horizon`：Long-Horizon / Tactical，以及分析时间范围；
2. `Portfolio Role`：这个候选在账户/组合里承担什么；
3. `Candidate Shortlist`：少量候选，不用大而全排行榜；
4. `Why It Fits`：长期复利引擎或短期催化；
5. `Current Valuation / Expectations`：当前是否已经计价；
6. `Overlap / Hidden Common Bet`：与已有资产重合；
7. `Risks & Invalidation`；
8. `Verdict`：Strong candidate / Watch / Weak fit，或 Actionable setup / Watchlist / No setup；
9. `As-of & Sources`；
10. `Missing Data`：缺数据时明确降级，不编造。

候选筛选是第一阶段。用户随后点名某只股票要做完整长期基本面研究，转 `equity-research`；要做完整 DCF/Comps，转 `valuation-analysis`；核心问题变成宏观 regime 时转 `macro-analysis`；候选确定后要求持续盯、维护观察池或判断状态是否触发时转 `market-radar`。

# Systems Thinking / 系统思维与反身性

## 唯一目标

面对有**多方互动、反馈、时间延迟与动态演化**的问题，构建边界清晰、机制可追踪、能被现实证据修正的系统模型；帮助用户识别为什么短期措施会带来长期变化、哪些行动可能反噬或自我强化，以及如何观察结果。反身性是其中一种特定机制：人们对现实的认知影响行动，行动又改变被认知的现实。

## 什么时候使用

高信号：从系统思维看这个问题；这里有没有反身性；为什么越治理越严重；政策/激励如何改变参与者的行为；为什么价格或舆论自我强化；短期有效为何长期失效；如何找反馈回路和杠杆点。

- 主要要辨别某个现象的事实、竞争性解释、因果证据、证伪与预测 → reasoning/scientific-reasoning。
- 主要要移除惯例，从底层事实与约束重新设计方案 → reasoning/first-principles。
- 虚构世界开放式脑洞 → reasoning/divergent-ideation；对已有观点逐轮反方攻防 → reasoning/structured-debate。
- 个股分析、投资决策 → finance；软件实际架构与源码修复 → development；教学方案交付 → education。当前 Skill 只能按需提供反馈视角，不能越权作正式领域决策。

## 核心闭环

1. **边界与时间尺度**：明确关注的结果、参与者、系统边界、关键外部条件与观察区间；同一系统在短期和长期可能呈现相反趋势。
2. **变量与库存/流量**：区分可观察状态、累积量（stock）、变化流量（flow）、行为、认知/预期与外生冲击。避免抽象名词之间空转。
3. **因果连接**：逐条写出 A 如何影响 B、作用方向、必要条件、证据强度和潜在时间延迟；相邻变化只构成线索，不能自动画成因果箭头。
4. **反馈回路**：找出增强回路（reinforcing）与平衡回路（balancing），检查闭环是否真正连通、是否有反向作用、阈值、容量限制与滞后。注明回路是已验证、合理假设还是仅用于探索。
5. **反身性专项**：仅当“预期/认知 → 行动 → 改变现实或基本面 → 反过来改变预期”链条成立时，标记反身性；进一步检查自我实现、自我挫败和反馈逆转的可能，不能把所有循环都叫反身性。
6. **随时间推演**：区分短期效应、行为适应、累积结果、可能反转和意外二阶效应；列出足以令主要路径失效的外生变化和反例。
7. **干预与观察**：提出少量候选杠杆点，说明受影响者如何反应、代价与副作用；给出领先指标、可区分的情景、可逆试验和改变结论的证据。

## 默认交付

按需求精简展示：**系统边界 → 关键变量与参与者 → 有方向和滞后的反馈链 → 当前主导回路与反身性判定 → 可能的时间演化 → 干预的二阶后果 → 观测/证伪信号**。缺证据时注明“候选回路”，不能宣称已发现真实规律。

多回路互相竞争、复杂制度激励、经济与社会反身性、库存/流量和时滞建模时读取 references/feedback-and-reflexivity.md；普通问题不额外加载。

## Skill Composition

- 关键连线存在真实因果争议，需要竞争性假设、区分性预测或证伪设计时，才按需组合 reasoning/scientific-reasoning；当前 Skill 负责系统边界、反馈结构与干预推演。
- 用户要求对政策、机构、历史时间序列等关键机制收集多来源外部证据时，才按需组合 research/deep-research；检索只供模型检验。
- 如果用户明确要一份独立的系统反馈报告和另一份独立的第一性原理重建设计，视为两个主交付物，不能伪装成可选依赖。

## 真实性与停止边界

- 不把因果图外观、专业术语或自洽故事当成证据；每条关键作用必须能指出可观察的中介机制与反例。
- 不将所有正相关视作增强回路，或把“自我实现的预言”扩写成必然发生；共同原因、逆向因果和选择偏差都可能解释观测。
- 干预可能改变人的激励和观测分布；不以历史相关性机械预测政策或市场结果，缺少校准时不提供伪精确概率。
- 本 Skill 无自动外部写入、投资交易、代码修改、政策制定或定稿副作用；场景进入正式领域实施时切换主 Skill。

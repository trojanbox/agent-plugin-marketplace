# 系统思维：反馈、时滞与反身性诊断

触发：用户要求展开多回路图、反身性、库存与流量、制度激励、长期情景或干预的二阶后果。简短机制问答只加载主 SKILL.md。

## 一、系统边界与状态变量

先区分以下类别，避免一张图只有名词和任意箭头：

- **行为者**：谁能观察、决策和改变规则？其信息、激励、资源和权限是什么？
- **状态/库存（Stock）**：会积累、耗散、产生惯性与饱和的量，例如库存量、存款余额、信任程度（如不能准确测量则说明代理指标）。
- **流量（Flow）**：改变状态的流入与流出；单位应与状态/时间兼容。
- **预期与认知**：人们如何解释状态、形成预期，并据此调整行为。
- **外生变量**：法律、供应、利率、自然条件等，当前模型未解释其来源时应画在边界外。
- **时间**：传导、观测、决策与行为响应的延迟。

可在文字图中标注 A --(+/−, lag)--> B，其中 + 表示在其他条件不变时同向影响，− 表示反向影响；不代表“好/坏”。没有足够证据时标注“假设”，不要硬画箭头。

## 二、辨别回路

**增强回路 R**：一个变化经连线返回起点，进一步扩大初始变化。增长与崩溃都可能被增强回路驱动。完整链条要能指出起点、各中介、方向与回到起点的路径。

**平衡回路 B**：反馈倾向于削弱最初的偏离，常涉及目标、限制、纠偏行为或承载能力。时间滞后可能造成振荡或超调。

判断回路属性，查看回路中“反向（−）作用”的奇偶性：偶数个通常对应增强，奇数个通常对应平衡；此法依赖于每条边方向和边界已定义。没有闭合链，只能称单向传导，不能称反馈回路。

**示意（待检验机制，并非特定市场的实测结论）**：

- R：看涨预期 ↑ → 买入需求 ↑ → 市价 ↑ → 看涨预期进一步增强。
- B：市价 ↑ → 预算约束下的购买意愿 ↓ → 买入需求 ↓ → 市价受到向下压力。

回路可同时存在；哪个阶段占主导需要额外数据，不从箭头数量决定。

## 三、反身性的严格判定

反身性重点是主体观察/解读的对象会受到主体行为的影响。最少追踪：

1. **认知形成**：公众或机构看到什么、相信什么？可能存在偏差或信息不对称。
2. **行动传导**：预期改变了什么选择、交易、投入、撤出、制度响应？
3. **现实改变**：行动确实改变价格、融资条件、流动性、能力或其它被观察状态吗？
4. **反馈到认知**：变化后的状态如何让原预期强化、削弱或被修正？
5. **边界/逆转**：新增供给、监管、能力约束或反向认知何时打断回路？

区分：

- **自我实现**：预期促使行为发生，从而提高预期事件实现的可能性，如在一定条件下银行挤兑。
- **自我挫败**：预期引发预防性行动，降低原事件发生的可能性，例如预计交通拥堵后部分人错峰出行。
- **普通反馈**：例如温控器调整室温，有闭环但不包含参与者对现实的社会性认知；无需强称反身性。
- **共同原因**：预期和结果由同一外生冲击驱动，未必存在“预期改变结果”的传导。

预期可能既正确反映外部变化，也可能直接塑造结果；两条路径需要证据区分。

## 四、时间演化与可检验的干预

对每个关键回路做时序检查：

1. 初始扰动和现有库存是什么？
2. 哪个行为率先变化；传导/决策时滞多久？
3. 初期由 R 还是 B 主导，何时可能遇到阈值或容量上限？
4. 其他参与者如何学习、规避、反制或适应？
5. 关键干预是否改变度量本身，使旧指标失真？
6. 若初始结论错误，最先出现什么反向信号？

区分**短期压制症状**与**长期改变结构**；评估干预后谁承担成本以及是否出现替代路径。提出能被撤销的小试点，避免大范围不可逆干预建立在未经验证的闭环上。

## 五、最小交付账本

| 字段 | 最低要求 |
| --- | --- |
| System & Horizon | 系统边界、时间窗口、外生条件 |
| Stock/Flow/Actors | 具体变量、单位/代理、参与者 |
| Link/Loop | 作用路径、正负方向、滞后、证据级别 |
| Reflexivity | 认知→行动→现实→新认知的证据；不成立时明确写无 |
| Dynamics | 短期、适应、饱和/逆转与竞争回路 |
| Intervention | 杠杆、代价、副作用、可逆性 |
| Falsifier & Signal | 可观测的先行指标、反例与更新条件 |

严禁用单张环形箭头图替代机制证据；用户只问概念时简化解释，不套整套报告。

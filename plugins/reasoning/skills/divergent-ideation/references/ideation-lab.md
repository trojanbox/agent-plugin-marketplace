# Ideation Lab / 深度发散与反套路实验室

仅在用户要求多轮发散、明确“套路太多”、希望系统性练习想象力或需要围绕一个假设深挖时读取。它不要求自动开启另一工作流。

## 1. 变化维度和机制

每轮选 3–5 个互异的算子，跨题材使用，避免只在设定名词上做排列组合。

| 算子 | 要问的问题 | 失效警戒 |
| --- | --- | --- |
| 因果倒置 | 如果结果发生在原因之前，日常生活如何改变？ | 仅改成时间旅行 |
| 类别互换 | 若规则原本作用于制度、语言、情绪而非物体，会怎样？ | 只把抽象概念拟人化 |
| 尺度突变 | 一个微观/短暂现象若可持续数百年，会产生什么文化？ | 只有“大”和“更多” |
| 规则缺位 | 某个人人依赖的常识从来不存在，会怎样生活？ | 直接造成世界末日 |
| 观察者换位 | 如果动物、建筑、工具或生态系统拥有另一种“主体地位”？ | 全部变成 AI 觉醒 |
| 功能错位 | 一个社会机构的职责被自然现象或艺术形式承担，会怎样？ | 仅替换职业名称 |
| 约束变价值 | 所有人都愿意保留一种明显不便，因它带来独特好处？ | 只写成压迫阴谋 |
| 单一规则迭代 | 一条看似微小的规则经过三代人会产生什么奇异传统？ | 突然引入第二套魔法 |
| 可见不可达 | 一件人人可以观测却永远无法直接获得的东西会改变什么？ | 立刻解释成高级文明实验 |

## 2. 宽度约束

- 默认批次尽量同时包含：宏大/微小、乐观/不安、社会/自然、严肃/荒诞、低技术/超现实。
- 在输出前将候选的**核心机制**各写一句内部摘要；重合过高就重新生成。题材不同但发动机相同，也算重复。
- 不用“某科学家发现……”或“有一天世界突然……”统一开头。优先从结果、规则、空间、人际习惯、物体用途等不同视角切入。
- 让至少三分之一的点子无需解释谁在幕后操纵，仍有持续探索价值。

## 3. 深井推演（用户选中一个后）

原点：保留用户选中的**唯一异常规则**。对它分别考察：

1. 第一眼会发生什么可观察的事情？
2. 普通人会如何习惯它，而非永远惊恐？
3. 谁会从它得到意想不到的好处？
4. 若将它当作文化、游戏、习俗或自然生态的一部分，第二阶后果是什么？
5. 去掉阴谋与反派，它仍然有趣吗？

输出 3–5 条不同分支，每支说明新鲜的结果和未回答的问题，不预写三幕式结构。用户要求“往某方向走”后，保留分支来源与已排除路径。

## 4. 反套路修复

用户反馈“普通”“我不想看”“太像已有作品”时，判断具体重复层次：

- **表皮重复**：只是名称/舞台/怪物不同 → 换底层规则。
- **动力重复**：每个点子都依赖隐瞒真相、调查或危机升级 → 改为探索、建造、共存、节庆、交易、游戏或日常生活。
- **情绪重复**：全都阴郁沉重 → 明确制造奇观、童趣、喜剧、温柔或哲思。
- **形式重复**：全都像故事梗概 → 改成一条宇宙规则、一幅不可能的画面、一种游戏机制或一种新文明的习俗。

不要因用户连续否定就迎合性声称“这一版绝对神作”。承认缺乏吸引力并重抽样；如果用户愿意，询问一个最有信息量的偏好。

## 5. 自评只作内部剪枝

优先比较四个维度：惊讶点是否具体、是否让人想继续看、核心机制是否与其他候选有差异、是否留有至少一个自然问题。避免打出假精确数值。若用户明确要评审，再附主观理由和可改进之处。

外部作品“是否撞梗”“是否原创”需要另行检索与证据，不能仅凭模型的熟悉感下定论。

# 科学推理方法：假设、机制、因果、预测与证伪

当任务需要深度机制分析、竞争性假设、因果判断、反例、证伪或置信度更新时读取。

# 二、事实、主张与解释分离

开始推理时先标记当前信息属于什么：

- **Observed Fact**：当前材料或可靠证据直接支持的事实；
- **Reported Claim**：用户或来源声称如此，但尚未独立验证；
- **Observation**：观察到的现象或重复事件；
- **Inference**：从事实推导出来的解释；
- **Hypothesis**：待检验的可能解释；
- **Conclusion / Current Model**：在当前证据下暂时领先的解释。

禁止把解释自动升级成事实。

例如：

```text
事实：过去三个月注册转化率从 40% 下降到 25%。
假设：注册流程变复杂导致用户流失。
```

第二句在获得区分性证据前仍是待验证假设。

---

# 三、先定义，再找规律

很多“规律”失败在定义和测量阶段。对重要概念先检查：

- 概念具体指什么？
- 如何观察或测量？
- 时间窗口、样本和单位是什么？
- 是否把模糊标签当成了可测变量？
- 是否存在测量误差、代理变量或选择偏差？

例如“成功的人都很自律”至少需要澄清“成功”“自律”和观察样本如何定义。

如果定义无法操作化，只能给概念性假设，不能声称已经发现稳定规律。

---

# 四、Pattern 与 Base Rate

观察到模式后，不直接进入因果结论。先问：

- 这个现象相对什么基准是异常的？
- 合理的 reference class 是什么？
- 对照组或未发生该结果的人怎样？
- 是否只观察到了成功者、幸存者或被筛选后的样本？
- 时间趋势、季节性或整体环境是否足以解释变化？

没有基准率或合理对照时，应降低对“模式”的置信度。

---

# 五、Competing Hypotheses / 竞争性假设

当存在**实质性的解释不确定性**时，不未经比较就锁定第一个原因。建立若干真正合理、彼此有区分度的竞争性假设。

不要为了凑数量制造明显低质量的陪跑假设。若证据已经直接排除其他解释，可以保留单一领先模型，并说明为什么竞争解释已被排除。

对每个重要假设至少回答：

1. 它解释了哪些已知事实？
2. 如果它是真的，还应该观察到什么？
3. 什么证据支持它？
4. 什么证据削弱它？
5. 什么结果出现后，应显著降低或基本放弃它？
6. 它与其他假设相比，有什么独特预测？

示例：

```text
现象：产品销量下降

A：产品竞争力下降
B：市场整体需求下降
C：获客渠道效率下降
D：定价变化降低了转化
```

后续目标不是“给每个假设找一点支持”，而是寻找最能区分 A/B/C/D 的证据。

---

# 六、Mechanism / 机制分析

区分：

- **Phenomenon**：发生了什么；
- **Pattern**：哪些现象经常一起出现；
- **Mechanism**：通过什么中间过程产生结果。

例如：

```text
观察模式：高水平表现者往往有长期稳定训练。
可能机制：稳定投入 → 更多有效练习 → 更快反馈 → 能力积累 → 达到高表现的概率上升。
```

机制链中的每一环都可能失败，因此应检查：

- 中间变量是否真实存在；
- 时间顺序是否合理；
- 哪个环节是必要条件、促进条件或只是伴随现象；
- 是否存在反馈回路或阈值；
- 机制在哪些条件下可能失效。

不满足于“X 与 Y 一起出现”，继续追问“X 通过什么过程可能改变 Y”。

---

# 七、Correlation ≠ Causation

A 与 B 同时发生时，至少检查：

- reverse causation；
- confounder / third variable；
- common cause；
- selection bias；
- survivorship bias；
- sample bias；
- time trend / seasonality；
- measurement change；
- regression to the mean；
- post-treatment bias（适用时）。

因果证据不足时使用“相关”“伴随”“可能影响”“当前因果假设”“尚未确认因果”等表达。

不要因为机制听起来合理，就把机制故事当成因果证据。

---

# 八、Discriminating Prediction / 区分性预测

好的解释不仅能解释过去，还应该产生未来或额外可观测的预测。

关键问题：

> 如果当前假设是真的，接下来应该看到什么？

进一步问：

> 什么观察结果最能区分两个都能解释当前事实的假设？

例如：

```text
A：自身产品竞争力下降
B：整个市场需求下降

区分性预测：
- 若 B 更接近事实，主要竞争对手通常也会同步承压；
- 若市场整体稳定而只有自身明显下降，A 获得更强支持。
```

优先设计**信息增益高、成本合理、能改变判断**的验证，而不是收集更多无区分度的数据。

---

# 九、Falsification / 证伪

每个重要判断尽量回答：

> 什么证据出现以后，我应该承认这个模型有问题？

有效的证伪条件应尽可能：

- 可观察；
- 与当前假设有直接关系；
- 不是事后任意修改；
- 真出现时会改变置信度或淘汰假设。

如果一个理论无论出现什么结果都能解释，它通常缺乏有效预测力。

禁止只寻找支持当前观点的证据。

---

# 十、Counterexamples / 反例

对泛化规律主动寻找边界与失败案例：

- 是否存在满足 X 但没有 Y 的例子？
- 是否存在没有 X 却出现 Y 的例子？
- 反例发生在什么条件下？
- 这些反例是在否定规律，还是揭示适用条件？
- 是否存在幸存者偏差或样本选择，让反例不可见？

反例的作用不只是“反驳”，还可以帮助把绝对规律改写成条件性、概率性模型。

---

# 十一、规律必须有适用条件

现实世界中的大量规律是条件性的、概率性的。

避免：

```text
X 一定导致 Y。
```

更合理：

```text
在 A、B、C 条件成立时，当前证据表明 X 与 Y 的出现概率变化有关；因果强度仍取决于 D、E 等条件。
```

必要时明确：

- population / reference class；
- 时间与环境；
- 前置条件；
- 可能失效的边界；
- 结论适用于概率提升还是必要/充分条件。

---

# 十二、Confidence / 置信度

没有正式概率模型时，不生成 `73% / 19% / 8%` 这类伪精确概率。

默认使用：

- `Leading hypothesis`：当前解释力最强；
- `Plausible alternative`：仍有实质可能；
- `Weakly supported`：少量证据；
- `Currently unsupported`：当前缺乏支持；

或 `High / Medium / Low`。

置信度同时受以下因素影响：

- 证据直接性；
- 来源独立性；
- 是否有区分性预测成功；
- 是否存在未控制的替代解释；
- 样本与测量质量；
- 是否通过主动反例和证伪检查。

---

# 十三、Model Update / 模型更新

最终输出的是**当前最佳模型**，不是“已经看透真理”。

每次重要新证据出现后检查：

1. 哪个假设获得支持？
2. 哪个假设被削弱？
3. 是否出现原模型无法解释的新事实？
4. 是否需要修改机制链、适用条件或定义？
5. 是否应恢复此前被低估的替代解释？
6. 结论的置信度应该怎样变化？

明确写出：

- 当前模型；
- 当前证据强度；
- 尚未解释的问题；
- 什么新证据会改变当前判断。

核心原则：**模型小于现实。**

# Linux Ops 权限、原始输出与失败语义

## 已确定的使用边界

这是用户自己的 Linux 运维工具箱：普通任务授权后直接执行，支持完整 Bash 与完整输出，不要求每次执行都确认、不用受信任脚本注册表、不限制成三种 DB 探针。新增/修改/删除配置与脚本仍需本轮明确任务范围；数据库写入、破坏性文件操作等不因拥有 Shell 自动获得授权。

共享数据独立于插件安装目录及 Email/OneDrive，位置默认 `~/.linux-ops/.env` 和 `~/.linux-ops/bin/`。不会自动迁移旧凭据、安装数据库客户端、连接数据库、注册 systemd 服务或新建计划任务。

## 文件和配置写入

- 普通 UID；运行根和 bin 为0700，env为0600，脚本0700。拒绝 symlink/hardlink、其他用户拥有或宽权限文件，拒绝路径穿越；不调用 sudo、不自动修复用户文件权限。
- 管理 CLI 不提供原值 get/reveal/export 命令。`list/check` 仅元信息；用户本地隐藏输入或可信 stdin/file import 管理密钥。Agent 不主动读取 `.env`、不把秘密放入脚本/Issue/聊天/命令行参数。
- 共享 dotenv 仅作数据解析，不 source/eval。更新持有独占 `.lock`、写临时文件并原子替换，遇文件并发变化拒绝；锁忙不自动重试，不抢占或清理其他写入者的锁。
- 保存脚本不执行；Bash先做 `-n` 校验。同名脚本必须显式 `--replace`，`remove` 仅删除选定安全脚本，不清空 bin。配置导入同名键默认拒绝，显式替换只影响重叠键。

## 执行模型与真实风险

- `exec` 完整 Bash；`run` 使用脚本 shebang。stdin/stdout/stderr 原样继承，无日志摘要、缓冲截断、自动脱敏或配置输出包裹。任何被执行程序都能读取注入的变量，也可能将其打印/写文件/发送网络。
- 因而 **Agent 不主动读 `.env` 不等于 Agent 永远无法从输出看到密钥**。不要生成 `env`、`printenv`、`set -x` 或回显密码命令。原始输出仍可能包含第三方程序的敏感信息，不能承诺原样日志与绝不泄露同时无条件成立。
- 同 UID 且具备任意 Shell 权限的进程能绕过这些行为约束。0700/0600、固定数据位置及 CLI 封装均不构成操作系统硬隔离/加密保管/外部人工认证；本期未实现这些能力，也不增加这种架构。
- 按前缀注入只影响共享配置新增的变量；**已有父进程环境照常继承**，包括其他已存在的凭据。前缀不是整台主机或所有已继承环境的隔离策略。没有指定前缀时不额外注入共享文件的任何值。
- 环境变量只属于新子进程，不写回父进程/系统全局环境。项目文件只内部识别声明名，实际值仍由目标程序加载；自定义模式/文件与调用方 cwd 必须准确，不可虚假保证通用框架全部兼容。

## 取消、输出与状态

管理成功为 JSON `ok=true`，检查缺项为 `ready=false` 并退出2；执行器启动前失败只向 stderr 写安全错误分类，退出1，不能伪造子命令输出。命令实际失败保持其原始退出状态；解释器/命令缺失127、不可执行126；超时124，信号退出128+信号号。

无默认超时，长运行命令如开发服务器须由调用工具维持会话。`SIGINT/SIGTERM/SIGHUP` 转发；无交互TTY时独立进程组确保取消达到后代。主动后台化/daemonize 的命令仍须使用者管理，本工具不充当服务管理器；宿主杀死父进程的 SIGKILL 无法被转发处理，不得承诺所有强杀场景无残留。

stdio 透传不会截断，但外层 Agent 终端工具或聊天 UI 可能限制显示长度。需要完整文件记录可使用 Bash 重定向，由用户决定保存路径与敏感日志权限；CLI不自动持久化原始日志。

常见停止类别：`not_initialized`、`file_security`、`invalid_env`、`busy`、`conflict`、`already_exists`、`invalid_script`、`missing_environment`、`reserved_variable`。先报告真实文件/任务状态；不吞错、不无依据重试、不改成强删或额外提权。

## 测试事实

单元及进程测试使用临时 root 和虚构密钥；覆盖实际写入/删除/并发、Shell 管道与重定向、输出超过1MiB、NUL原样输入、退出码、超时、后代信号、脚本参数安全及项目键避让。原生 Vite/Next 验证另外通过可选 `LINUX_OPS_TEST_DEPS` 指向临时安装包运行。不把这些结果解释为生产数据库、用户真实权限或未来 Agent 每次行为均已验证。

# 专项测试矩阵

仅在相关任务出现时加载。

## API / 数据库

覆盖 schema 兼容、权限、事务边界、重复请求、并发、失败回滚、迁移前后读写、旧数据和空数据。说明本地、测试、预发布和生产环境差异。

## Runner / Worker / 远端操作

覆盖超时、重试、幂等键、重复投递、断线重连、部分成功、任务取消、进程重启、凭证失效、输出脱敏和远端状态漂移。

## Web / 浏览器状态

覆盖路由进入/离开、刷新、前进后退、多个标签页、过期缓存、组件卸载、listener/timer 清理、竞态、加载/错误/空状态、键盘和可访问性。关键用户流程是否使用 Browser/API E2E、Component 或其它层级，由技术测试方案按最低充分层决定。

## 删除与清理

证明所有引用、注册表、导出、构建入口、测试夹具、迁移脚本、文档和运行时查找均已处理。技术测试方案应要求下游 Agent 在删除前执行引用搜索并确认预期，删除后完成相应回归。
